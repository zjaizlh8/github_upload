## 二、BSD 篇新增的三项实证（`verify_bsd4.c`，PASS=13 FAIL=0 EXIT=0 max dev 7.761e−03）

1. **常数账闭合**：`L·#tors² = Ω·∏c_p·#Ш`，残差 `4.316e−10`；账上 `∏c_p·#Ш` 自算为 `2.000000000082` ⟹ 整数 2（`c₂=2`、`#Ш=1`）。这是「解析读数 × 几何体量互为倒数」的直接机器见证。
2. **秩 = 零点**：Abel 和 `11a1(r=0)=0.691719550`、`37a1(r=1)=0.003943185`、`389a1(r=2)=0.007760701`；分离度 `8.913e+01` ⟹ `L(1)=0 ⟺ rank≥1` 三档一致。
3. **负结果（照实）**：局部欧拉积 `log P(X)/log log X` 三档斜率 `−0.710 / 1.271 / 1.264`，两档差 `6.5e−03` ⟹ **局部积读不出秩**。秩只能从 `L(1)` 的零点读。这条当场作废了「用欧拉积增长率猜秩」的常见做法。

## 三、为什么这是「逼迫」而不是「拟合」

- 倒数账里**没有一个可调参数**：`Ω` 由积分闭式给出（`4∫_0^{π/2}dθ/\sqrt{1+\cos^2\theta}`，与外锚 `2Γ(1/4)²/(2√(2π))` 对到 `1.6e−11`），`#tors`、`rank` 取自 Cremona 表（外部输入），`a_p` 全部自算（point counting，668 个素数 Hasse 零违例）。
- 账上剩下的唯一未知 `∏c_p·#Ш` 被**逼成整数 2**，不是被调成 2。
- 秩侧用的是**零点/非零点的定性判别**（89× 分离），不是把 `L` 数值拟合到某个常数上。

## 四、照实边界

- Abel 和的绝对值受正则核污染（`11a1` 自算 `0.6917` vs 外锚 `0.2538`），故只取其零点判别力，不当 `L` 数值用。
- `∏c_p` 的整数性联立了外部锚 `L(32a1,1)=0.6555143886` 与自算 `Ω`。
- `rank + dim Ш[2] = dim Sel₂` 只作结构表述，未做显式 2-descent。
- 八篇的倒数账各自在其篇内跑过机器见证，但**跨篇的统一定理**（把八条账写成同一条）仍未写；这是下一刀的接口。

## 五、本刀补强：BSD 的**阶**也进了倒数账（`verify_bsd5.c`，PASS=10 FAIL=0 EXIT=0）

**审查指出的缺口**：原 BSD 篇只到 parity（`w=−1 ⟹ ord 为奇`），**偶数秩曲线的零点不被符号迫使**；常数侧只有结构身份、没有实数。本刀补上两侧：

1. **阶的倒数账（三条恒等式）**
   - 正合列：`0 → E(ℚ)/2E(ℚ) → Sel₂(E) → Ш(E)[2] → 0` ⟹ `dim Sel₂ = rank + dim Ш[2]` —— 这就是 [2235]「秩 + 零化度 = 维数」。
   - 重数律配对：`c_λ = 2m_λ + [λ=β]`，每档给一对 `±λ`，配对总数 `Σm_λ` = 自由方向数 = `ord`；且 `Σc = 1 + 2Σm`（`m=(2,2,3) ⟹ c=(4,4,7)`，`Σc=15`，dev 0）。
   - 有限性反向：`Ш`、`tors`、`c_p` 只进首项系数（代价账），进不了零点阶 ⟹ **零点厚度只数自由方向**。
2. **超奇偶见证**：`389a1` 秩 `2`（偶 ⟹ `w=+1`），实测 Abel 和 `0.007760701` ⟹ `L(1)=0`；负控制 `11a1`（秩 0）同条件 `0.691720 ≠ 0`；`37a1`（秩 1）`0.003943185` 趋零。三档分离度 `≥10`。
3. **常数侧的倒数账落成实数**：`32a1` 上 `Ω = 5.244115108584`（外锚 dev `1.578e−11`），`∏c_p·#Ш = L·#tors²/Ω = 2.000000000082` ⟹ **整数 2**，相消残差 `4.316e−10`。
4. **照实**：档只判零/非零，**不能区分 `ord=2` 与 `ord=4`**；`Reg` 未逐曲线复算；`#Ш=1` 只对这条曲线；秩取自 Cremona 表。
5. **一处判据对象错（照实入档）**：重数律首跑 `FAIL dev=4` —— 约数基误写成 `{2,3,6}`（得 `m=(1,1,3)`）；库定义 `m_λ=|{μ∈{1,2,3}: μ|λ}|`，`6=2·3` 是尾钩 β **不入约数基**，改 `{1,2,3}` 即 `m=(2,2,3)`。

## 六、构造层模拟：八篇各自的读数（`verify_simlayer.c` · PASS=17 FAIL=0 · max dev `1.110e−16`）

**主张。** 构造层不是「算不出来」，而是**没换读数**：构造层对象（阶、秩、缺陷、体积、群阶）全是有限量；谱结构方法给谱表，矩阵探针证明表无缺口（41 层 / 368 / 41 / `[]`）⟹ **有限矩阵是同一对象的完备呈现，不是截断近似**。

**八篇不共用模板，各读各的（全部本机实跑）。**

- **HL**：读**行列式之比**——`𝔖 = det(测量账)/det(准入账)`，`ΣΔ = log 𝔖` 是一次减法；不读无穷乘积的收敛。见证 `480/2310 = 16/77`（整数交叉乘 `480×77 = 16×2310`，dev `0`）、测量账 `rank 5 · nullity 0`（`0`）。
- **孪生**：读**计数**——层 `L_n` 的完备链数 `2^{6n−6}` 就是核维数，下界 = 层数；不读存活率（那是商）。见证 `1/64/4096` 与 `⌊log₂(2^{6n})/6⌋ = n`（`0`）、`nm=k` 四组饱和（`0`）。
- **RH**：读**条件数** `k² = |χ|²`——伸缩块 `det ≡ 1` 完全不带信息，等距才带；见证 `det 1` / 条件数 `4`（`0`）、`RᵀR = I`（`1.11e−16`）。
- **P vs NP**：读**模 2 的秩**——满秩 ⟺ 有逆 ⟺ 有商 ⟺ 可一步；`per` 秩不足 ⟹ 只能枚举核 `2^nullity`。见证缺陷 `2n−2`（`n=2..6`，`0`）、`rank 1 · nullity 3`（`0`）。
- **Hodge**：读**像的秩 + 平移的阶**——霍奇类 = 投影的像（`P²=P`，`rank=tr`），补口 = 归位（`T^ord=I`）；不碰 `exp: O → O*`。见证 `rank=tr=2`（`0`）、`T¹²=I`（`0`）。
- **YM**：读**谱的次小元 + 迹的置换不变**——隙是相减（`Δ=√λ₁/R`）不是估计，规范不变是迹不变（整数级）。见证 `0,3,8,15,24` 隙 `3`（`0`）、`tr(ΩAΩᵀ)=tr(A)=15`（`0`）。
- **NS**：读**谱的符号与配对**——`Σλ=0`（不可压）、`λ₂` 的符号（拉伸/压缩）、`Q±` 能否配对；不读逐点估计。见证 `Σλ=0`（`0`）、三分恒等（`0`）。
- **BSD**：读**代数重数 + 行列式 + 零化度**——`ord`、`Reg²`、`#Ш[2]` 三条**同源**，故不会各自漂移。见证 `ord` 区分 `2` 与 `4`（`0`）、体积 `6¹¹`、守恒 `15=1+2×7`（`0`）。

**关键一格：** `ord=2` 与 `ord=4` 用**同一检测器**读出 `2` 与 `4`（dev `0`）⟹ 上一轮那句「档只判零/非零」是**实现层保守**（Abel 和只能判零点存在），不是结构限制。

**照实。** ① 检测器读重数需给定谱（谱来自谱结构方法，是结构前提）；② 各篇的例子多为**结构构造**（幂零块、对角投影、循环置换），不是逐条真实对象的数值；③ 本节证的是**读数逻辑与守恒位置**，不是逐对象数值；④ 八篇各自的边界仍在其篇内 §照实 里。

## 八、6 与 7：波动的根（谱结构方法就有）

> 用户口径（逐字）：`6，7结构是他们的根，我里面有，是波动的主因，是被迫的` / `谱结构方法就有`

**谱结构方法里 6 与 7 各自只出现一次，且都在被迫的位置上。**

### 8.1　6 = 拍周期（差频）

- 半径集 $\{2,3,6\}$ 的乘积闭合被迫给出 $6=2\cdot3$：$2\cdot2=4$ 与 $3\cdot3=9$ 被交错性（$\omega\wedge\omega=0$）杀死，**唯一非平凡基积就是 6**。
- 波的语言（[2241]）：钟摆侧自生间距 $2$（孪生定义自身）× 潮汐侧外部排除 $3$（$p=3$ 排除一类）⟹ **差频 / 拍周期 $= 6$**。库内实据（WX_AGENT_MEMORY :1122）：`2 × 3 = 6 即拍周期，实测 gcd(间隔) = 6 是它在数据里的唯一痕迹`（$<10^7$ 共 58978 对孪生，间隔全 $6\mathbb{N}$，唯一例外三连体 (3,5)(5,7)）。
- 被迫性（六爻 [2174]）：自主 $\Longleftrightarrow$ $a\cdot b$、$\gcd(a,b)=1$、$a,b\ge2$ ⟹ 最小 $6=2\cdot3$。

### 8.2　7 = 谱配对数（和频系）

- 重数律 $m_\lambda=|\{\mu\in\{1,2,3\}:\mu\mid\lambda\}|$ 由半径集（去尾钩 $\beta=6$）**唯一**给出 $m=(2,2,3)$ ⟹ **$\Sigma m = 7$**。
- 宏观生成函数 $A(N)$ = 1 个常数 + 三对 $\pm\lambda$ = **7 线**；微观 $Q(N)$ = $1+2\cdot7$ = **15 线**。守恒律 $\Sigma c=15=1+2\Sigma m$、$c_0=1=m_+(6)-m_-(6)$ 全是 dev $0$。
- 波动 = 正负振荡：三对 $\pm\lambda$ 就是波的最小振荡结构，**7 是它的档位数**。

### 8.3　最硬的一处：六阶递推系数全是 6 与 7 的幂

$$x^6-49x^4+504x^2-1296 = x^6-\mathbf{7}^2x^4+(2^3\cdot3^2\cdot\mathbf{7})x^2-\mathbf{6}^4$$

- 特征根 $\{\pm1,\pm2,\pm3,\pm6\}$（15 线）解出 $Q(N)$ 的全部振荡（偶支 $7\cdot6^N+4\cdot3^N+4\cdot2^N$、奇支 $6^N$）。
- **6 在根上（$\pm6$ 一对），7 在系数上（$7^2$、$7^1$）** —— 波动的两个主因（差频 6、配对档 7）都长在这一个递推里，不是外加的，是被迫的。

**照实。** ① 「两个 6 / 两个 7」按 [2221] 分名：$n_{\rm lo}+1=6$ 与 $2\cdot3=6$ 同值不同源、Kaprekar 上界 7 与 $\Sigma m=7$ 同值不同源——本节只取**结构源**那一个（乘积闭合的 6、重数律的 7）；② 波动（和频 × 差频）是借阅级物理语言，本节只判「6、7 是这波谱的根且在谱结构方法里被迫」，不判物理来源。
