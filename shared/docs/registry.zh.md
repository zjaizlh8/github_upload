## 跨篇统一定理：接口留白（照实）

八篇共用同一套「容器 · 空间 · 对称」语言，但**跨篇的统一形式化定理尚未写出**——这是一处**接口**，不是已证结论。可核对的共享物只有三件：

1. **容器**：`Z₂^k` / `Λ•` / 特征多项式系数空间上的有限格；判据只能落在**系数**上（相似变换不变量）。
2. **对称**：一律为对合（`σ`、`τ`、`w=(−1)^k`、综/错）；判据 = 该对合下**不变**或**翻号**的量。
3. **闭环**：一律要求 `R(F(x)) = x`（出去一圈原路归位），残差 `res` 由机器见证给出，不写常量。

⟹ 本仓提供的是**八条同构但分别陈述**的路径，**不是**一条统一证明；若日后写出统一形式化，本表第 1–8 行的承重引理可以合并为一条，届时再改定理头。
