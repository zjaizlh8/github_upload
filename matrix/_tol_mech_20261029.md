# 台账 tol 机制体检（2026-10-29 · §179）

> 一句话：`matrix/forcedness_ledger.csv` 的 `tol` 列在多数行上是**手给的圆整界**（`1e-13`/`1e-8`/`1e-9`/`2e-2`），
> 而 `§178` 已经量出「`tol` 的十进制指数减 `dev` 的指数，88.3% 落在 +1…+3」——即 `tol` 是 `dev` 的影子。
> 本档把这件事变成**能翻红的机械判据**：三条规则 + 一处降级 + 六条齿，并把能导出机制的行改写成机制界。

**作者确认: 2026-10-29 · YG**（`tol` 改由机制导出；不改任何期望值、不改判定方向、不改判据对象；事故原型是「容差拍脑袋」，见 G54·R3）

## §179.0 层位与口径（先说清再判）

| 项 | 内容 |
|---|---|
| 层=结构 | 行内 `class` / `dev` / `tol` / `ratio` 四列的**互相约束**（`class` 跟随 `dev`、`ratio = dev/tol`、`tol` 由机制导出） |
| 层=过程 | `dev` 随窗口/规模的漂移，只报 TREND（本档不把过程面读数逼成 0） |
| 判据的判据 | `tol` 若取自本次读数（`tol ≈ 2·dev`）⟹ **自比**，永不可能 FAIL ⟹ 判别力 0（与 G53「总和 = 行数」同型） |
| 不承担证明 | 本档只说「这个界是不是手给的」；**不说**该行的数学内容成立与否 |

**桶序**：`FORCED → FORCED_eps → FORCED_trunc → FLOW → DUP → TREND`（与台账判定同序；缺口 = 0，六档合计 = 198）。

**重复计数（三个数都写）**：`TOTAL=198` 行 · `INDEP=183` 组（按 `(篇,块,标签,骨架)` 归组）· `重复(参数点)=15` 行 —— `198 − 183 = 15`。

## §179.1 三条规则（`matrix/tol_mech.awk`，可重跑）

| 规则 | 判法 | 处分 |
|---|---|---|
| **R0 豁免** | `dev == 0`（整数域/恒等）⟹ 无 `tol` 可绑 | 记 `OK_ZERO`，不判（G54：整数域严格 0 本身就是律） |
| **R1 反抄** | `tol / dev ∈ (1.9, 2.1)` ⟹ 界取在 `dev` 的 2 倍附近 | **必降 TREND**（自比界，判别力 0） |
| **R2 机制界** | `tol/u ∈ [0.5, 100]`（`u = 2⁻⁵²`）记 `OK_MACH`；或 `criterion` 明写 `1/N`、`1/h`、`h^p`、`收敛` 记 `OK_ORDER` | 保留，机制可核 |
| **R3 其余** | 圆整十进制界 / 拍脑袋界 | **只报不判**（`NO_MECH`）：它是**松界**，能 FAIL，只是没人给过机制；不当作缺陷乱改 |

> R1 的窗口取 `(1.9, 2.1)` 而不是「严格 2×」：手给界几乎不会正好等于 2 倍，但会落在 2 倍附近 ——
> 实测 `ym:84` 为 `tol/dev = 2.00097`，若按「严格 2×（±1e-6）」判就漏掉了（**这是本档第一次跑出 R1=0 的原因**，照实记）。

## §179.3 逐行改动（15 行，全部有机制推导）

### (a) `bsd:42/72` Ω 与外锚一致 —— `tol: 1e-8 → 1e-10`

机制：`Ω` 由 Simpson 复合公式算（`verify_bsd.c:647` `S1_omega_32a1`，`NPTS=200000`，`h = π/2/NPTS ≈ 7.85e-6`）：
- 截断项 `~h⁴ = 3.8e-21`（可忽略）；
- 主导项 = **双精度累加界** `ε·NPTS·max|f|·(4h/3) ≈ 1e-10`（`f ≤ 1`，`s ≤ 4·NPTS`）。
⟹ `1e-10` 是累加界；`1e-8` 是圆整手给（宽 100×，仍能 FAIL，但没有机制）。

### (b) `bsd:44/73` Tamagawa 积 = 整数 2 —— `tol: 1e-9 → 1.53e-10`（台账记 `2e-10`，见下）

机制：`tam − 2 = (16·(L真 − L锚) + 2·(Ω真 − Ω算))/Ω`，两个误差源**独立相加**：
`(16·½·10⁻¹⁰ + 2·1e-10) / 5.2441151086 = 1.53e-10`。
探针打印格式为 `tol=%.0e`（`verify_bsd.c:673`）⟹ 台账记 `2e-10`（**上界不被缩紧**），机制界原文写在 `criterion` 列里。

### (c) `bsd:46/74` 倒数账相消 —— `tol: 1e-9 → 8.0e-10`（本档最硬的一条）

机制：`dev = 16·LEXT − 2·Ω`，而 `LEXT = 0.6555143886` 只取 **10 位**（`verify_bsd.c:711`，**独立外部锚，禁由恒等式反推**）。
`LEXT` 的舍入上界 `½·10⁻¹⁰` ⟹ `|dev| ≤ 16·½·10⁻¹⁰ = 8.0e-10`。

> **预测值检验（不是拟合）**：`L真 = Ω/8 = 0.65551438857303` ⟹ `16·(L真 − LEXT) = 4.315e-10`；
> 实测 `dev = 4.316e-10` ⟹ **四位吻合** ⟹ 这条残差 **100% 来自锚截断**，不是恒等式失败。
> 这正是 G54·R1「律要能被机制算出」的形状：**先算出残差该是多少，再去看跑出来是不是这个数**。

### (d) `hl:7/9/11/54/67/114` 与 `bsd:60` 七行 `FLOW` —— `tol: → NA`

`FLOW` = 有限窗流体量（**过程面读数**），`tol` 对它没有结构含义（S1：过程只报走到哪儿）⟹ `tol`/`ratio` 记 `NA`，
`criterion` 追加「FLOW 是过程面读数（S1），tol 无结构含义 ⟹ 清 NA」。

### (e) `bsd:50/51` rank 1/2「Abel 和趋零」—— `DUP → TREND`，`tol: 2e-2 → NA`

「趋零」是过程面（走到哪儿），固定 `2e-2` 的界只是把一个有限 `δ` 的读数当判决；
`rank ≥ 1 ⟹ L(E,1) = 0` 的结构内容由 part3 的整数域判据承担 ⟹ 这两行降 `TREND`。

### (f) `ym:84` P3 physical gap —— `FORCED_trunc → TREND`（R1 命中，见 §179.2）

## §179.4 齿（`audit/tooth_tol_mech.c` · `RESULT PASS=6 FAIL=0` · 已挂 `audit/run_chain.sh`）

| 齿 | 内容 | 实测 |
|---|---|---|
| T1 | `dev(Δ=0) ≤ 8.0e-10`（不误伤基准行） | `4.315677e-10` PASS |
| T2 | `Δ=+5e-11` ⟹ `dev = 1.2316e-9 > 界`（**咬得住**） | `8.0e-10 / dev = 0.6496 < 1` PASS |
| T3 | `Δ=+2e-11` ⟹ `dev = 7.5157e-10 ≤ 界`（**不是过紧**） | PASS |
| T4 | `sdev(Δ) − sdev(0) = 16Δ`（线性预测，残差 ≤ `16·½ulp = 1.8e-15`） | `6.62e-17` PASS |
| T5 | 自比界（`2×dev`）对 4 个扰动 **0 次拒绝** ⟹ 判别力 = 0 | PASS |
| T6 | 机制界对同 4 个扰动 **≥1 次拒绝** | 1 次 PASS |

**判别力对照（独立对照，两界取自不同来源）**：机制界拒绝 `1` 次 · 自比界拒绝 `0` 次 ⟹ **两界不同形，不是同一件事的两种写法**。
T4 的教训：线性预测只对**带符号**残差成立（`Δ<0` 时 `|dev|` 反而变小）；第一版用 `fabs` 写 T4 当场 FAIL（`8.63e-10`），改带符号量后残差 `6.6e-17`。
