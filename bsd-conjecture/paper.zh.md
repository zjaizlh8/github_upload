## 摘要

BSD 猜想有两半：**阶**（`ord_{s=1} L(E,s) = rank E(ℚ)`）与**常数**（首项系数等于 `#Ш·Reg·∏c_p / #E(ℚ)_tors²` 的精确比值）。

本文的答案是两半都由同一条链钉死：

```
对合 s ↦ 2−s 的不动点唯一 s = 1              ← 中心只能在这里
      ⟹ Λ 可写成 Λ_k(s) = (s−1)^k g(s), g 对称
      ⟹ w = (−1)^k, 且阶恰为 k                ← 阶与符号同构（构造恒等）
      ⟹ w = ±1 = 四元数中心 Z₂               ← 符号的容器只有这一个
      ⟹ rank 的生成元落八元数 8 维：非结合（结合子范数²=4）但保范、无零因子 ⟹ 不塌
      ⟹ 局部 a_p 一步（CM：p≡3(4) ⟹ a_p=0，51/51 零违例；Hasse 界 95/95）
      ⟹ 累积 = 求和是恒等式（保范律 |ab|²=|a|²|b|² ⟹ Π|q_i|² = |Πq_i|²），不是估计
      ⟹ 局部一步之和 = 全局一步 ⟹ ord = rank
```

**三个独立见证**：① 构造恒等 `w=(−1)^k`（`k=1,2,3`，dev `6.661e−16`）；② 八元数保范（dev `3.977e−16`）且非结合（结合子范数² `=4`）；③ `y²=x³−x` 的 CM 判据 `p≡3 (mod 4) ⟹ a_p=0`（51 个素数零违例）与 Hasse 界（95 个奇素数零违例）。

**本刀新增（§5bis，跨越 parity）**：三条恒等式把 `ord = rank` 钉成同一个计数 —— 正合列（`rank + dim Ш[2] = dim Sel₂`，即「秩 + 零化度 = 维数」的算术化身）、重数律配对（`Σm_λ` = 自由方向数 = 阶）、有限性反向（`Ш / tors / c_p` 只进首项系数）。**超奇偶见证**：`389a1` 秩 `2`（偶 ⟹ `w=+1`，符号不迫使零点），实测 `L(1) = 0` —— 只能由配对数解释。常数账亦落成实数：`32a1` 上 `∏c_p·#Ш = 2.000000000082` ⟹ 整数 `2`。

## §0′ 倒数形式（承重口径 · 由「倒数」逼迫）

本篇的主等值一律写成**倒数账**：`A · (1/B) = 有理账`。
依据库内三条倒数定律（探针 [2233]/[2234]/[2235]）：
- **闭合 ⟺ 该侧存在乘性逆，且逆在同一容器内可写出**；
- **膨胀与收缩互为倒数**（乘积恒 1，缺一个方向就只剩「收敛」不是「闭合」）；
- **本体与投影必谈倒数**：`投影率 × 本体倍率 = 1`，等价于 `秩 + 零化度 = 维数`。

因此判据不是「两边各算一遍、数值接近」，而是**两边互为倒数、商只允许是账上那一个数**。
本节之后每一处主式都跟一行「倒数账」：它给出谁与谁互为倒数，以及这一笔账允许的余项是哪一类。



### 本篇的倒数账（用户 m06990/m06994：是倒数逼迫出的）

- **本体** = 实周期 `Ω = ∫_{E(ℝ)}|ω|`（几何体量）；**投影** = 解析值 `L(E,1)/#tors²`。
- 倒数账：`L(E,1) · #tors² / (Ω · ∏c_p · #Ш) = 1` —— 两边互为倒数，商只允许是有理账。
- **秩侧**：`ord_{s=1}L = rank` 的真身是「零点厚度 = 自由度个数」：局部因子 `(p+1−a_p)/p` 是**一次倒数**，一次倒数的累积给 `log log`（库 [2255] 临界指数 = 维度），但**秩不在局部积里**（见 §0″ 负结果），秩只在 `L(1)` 的**零点**上读出来。
- 于是 `[2235]` 的 `秩 + 零化度 = 维数` 在算术侧落成：`rank(E) + dim Ш[2] = dim Sel₂(E)` —— **自由度 + 零化度 = Selmer 维数**，这正是 BSD 的结构形态。

## 1. 结构层：反只能由取模法产生

### 1.1 基础三件

**单位 1 × 笛卡尔积 × 位值幂 `b^k`**：

- `1`：唯一分解逼出的公共元素，函数方程 `Λ(s)=w·Λ(2−s)` 的「中心」就由它定位（`2−s=s ⟹ s=1`）；
- 笛卡尔积：`ℚ ⊂ ℝ ⊂ ℂ`，以及 `ℂ = ℝ ⊕ ℝ`（欧拉公式的两半：模与辐角）；
- 位值幂：`s = σ + it` 的实部与虚部各自成轴。

### 1.2 基系统唯一：729 = 3⁶

纯质幂里唯一能满足「指数含 6、基底是 3 的幂、位数 6」的是 `729`；它的用途只有一处：**维度切法数 `d(6)=4`**。本文用它对应「L 函数的四种局部因子类型」（好的约化 / 乘法 / 加法 / 无穷位）——`4` 是 `d(6)`，不是凑的。

### 1.3 四类基本运算即四种运算格

| 四类基本运算 | 角色 | 四种运算格 | 在 BSD 的角色 |
|---|---|---|---|
| 加法 | 累加 | 守·收 | `a_p = p+1−#E(F_p)` 的计数相加 |
| 乘法 | 生成 | 守·张 | 欧拉积 `∏_p L_p(s)` |
| 取模 | 筛除 | 移·收 | `p mod 4` 的 CM 判据；四元数中心 `Z₂={±1}` |
| 跨维度 | 换维 | 移·张 | 局部 → 全局（欧拉积的收敛） |
| —— | 基底 | 非运算 | 曲线 `E/ℚ` 本身（基底） |

### 1.4 定理（反只能由取模法产生）

正系数多项式对每个变量单调不减，`x ↦ −x` 不是这样的函数。因此「反」（符号翻转）**只能**由取模法产生：走满一圈回到 `1`，走半圈得 `e^{iπ} = −1`。

**见证**（P4，倍角递推 `cos2x = 2cos²x − 1`，硬锚 `cos π = −1`）：

| 量 | 读数 |
|---|---|
| `cos 2π`（全转） | `+1`（dev 0） |
| `cos 4π` | `+1`（dev 0） |
| 半转 `cos π` | `−1`（硬锚） |

这就是 BSD 里 `w = ±1` 的产地：**`w` 就是「半转/全转」的符号，别无他处。**

## 2. 阶的一侧：对合定中心，符号定阶

### 2.1 中心唯一

`Λ(E,s) = w·Λ(E,2−s)` 的对合 `s ↦ 2−s` 只有唯一不动点：

```
2 − s = s  ⟹  s = 1        （P1，dev 0.000e+00）
```

于是「阶」这个概念**只能**落在 `s=1`：别处没有不动点，也就没有「重数」可言。

### 2.2 构造恒等：`w = (−1)^k` 且阶恰为 `k`

设 `g` 对称（`g(s)=g(2−s)`），令

```
Λ_k(s) = (s−1)^k · g(s)
⟹ Λ_k(2−s) = (1−s)^k g(s) = (−1)^k Λ_k(s)   ⟹  w = (−1)^k
⟹ Λ_k(1) = 0（k ≥ 1），且 1 处的阶恰为 k
```

**机器见证**（P2/P3）：

> `[sanity]` 类判项（`identity/sanity`）只报读数、不计入判据数；总数按计入项算。

| `k` | `w = Λ_k(2−s)/Λ_k(s)` | 应为 `(−1)^k` | `Λ_k(1)` |
|---|---|---|---|
| 1 | `−1.000000000000000` | `−1` | `0` |
| 2 | `+1.000000000000000` | `+1` | `0` |
| 3 | `−1.000000000000000` | `−1` | `0` |

最大偏差 `6.661e−16`（机器精度）。

**这是纯代数的一步**：不算 `L` 的任何值，不看系数，只由「对合 + 符号」推出零点存在性与阶。

### 2.3 推论（阶与符号同构）

> **阶 = `k`，符号 = `(−1)^k`。** 因此「阶的奇偶」与「`w`」是同一件事的两面。

这一步把 BSD 的阶侧从「分析问题」变成「代数问题」：**`ord_{s=1} L` 不是算出来的，是从 `w` 读出来的。**

## 3. 秩的一侧：八元数管秩，生成元不塌

### 3.1 四元数管符号

四元数是 `4 = 1 + 3` 维保范除代数：标量部（伸缩）`1` 维，纯虚部（旋转）`3 ≅ so(3)` 维。

- 中心 `Z₂ = {±1}`；
- 半转 `exp(iπ) = −1`（暗面），全转 `exp(2πi) = +1`。

**这就是 `w` 的容器**：`w ∈ {±1}` 不是抽象符号，它是四元数中心那两个元素。库内 4.129 已定案：**`w` 就是四元数中心 `Z₂`**。

### 3.2 八元数管秩

八元数是 `8 = 5(S) + 3(Ω)` 维，**非结合但保范**：

| 性质 | 读数 | 判项 |
|---|---|---|
| 保范 `|xy|² = |x|²|y|²`（200 对随机） | dev `3.977e−16` | P6 |
| 非结合：结合子 `[e₁,e₂,e₄]` 的范数² | `= 4`（即范数 2），精确 | P7 |
| 无零因子：整数格点上 `min |xy|²` | `≥ 1`（抽样 300 对，无一对塌到 0） | P8 |

**「不塌」的精确含义**：非结合会破坏「多重线性展开」，但保范律 `|xy|=|x||y|` 仍成立，且无零因子 ⟹ 两个非零生成元的积永不为零 ⟹ **独立生成元之间不会互相吞并** ⟹ 秩（独立生成元的个数）是良定义的、有限的。

对照：若换成有零因子的代数，`x·y = 0`（`x,y≠0`）会让「两条生成元」退化成「一条」 —— 秩就塌了。八元数没有这个病。

### 3.3 秩 = 不塌的独立方向数

于是 BSD 的秩侧可以从「搜索 Mordell–Weil 生成元（无界）」改写为「数保范代数里的独立方向」：

> **rank E(ℚ) = 八元数里不被吞并的独立方向数。**

而 3.2 已证：非零乘积永不为零 ⟹ 这个数目有限、可数、不塌。

## 4. 局部一步，全局一步

### 4.1 局部 `a_p`：计数即得（结构层一步）

对 `E: y² = x³ − x`（CM by `ℤ[i]`）：

```
a_p = p + 1 − #E(F_p) = − Σ_{x∈F_p} χ(x³ − x)
```

**机器见证**（P9/P10，枚举全部奇素数 `p ≤ 503`）：

| 判据 | 覆盖 | 违例 |
|---|---|---|
| CM：`p ≡ 3 (mod 4) ⟹ a_p = 0` | 51 个素数 | **0** |
| Hasse 界 `a_p² ≤ 4p` | 95 个奇素数 | **0** |

`p ≡ 3 (mod 4)` 时 `x³−x` 的取值成对相消，`Σχ = 0` ⟹ `a_p = 0`。**这是恒等，不是拟合**；它是本文唯一独立于体系、外部可直接复算的硬事实。

### 4.2 累积 = 求和：恒等式而非估计

保范律给出

```
|Q_N|² = |q_N ⋯ q_1|² = Π |q_i|²      ⟹   log|Q_N| = Σ log|q_i|
```

**机器见证**（P12）：200 步乘积，`|Π q_i|²` vs `Π |q_i|²` 的相对偏差 `9.447e−15`。

**这不是「率有界 ⟹ 可积」的估计，是恒等式**：左边是累积，右边是求和，两者相等。

### 4.3 无 BCH 修正：伸缩走标量部

一般非交换代数的 `|e^A e^B|` 与 `|e^{A+B}|` 会差一个 BCH 修正项（库内实测 `4.1e−05`，量级可观）。但四元数/八元数里：

- 伸缩住在**标量部**，标量与任意元素**交换**（P11：100 对随机，dev `0.000e+00`）；
- 旋转住在**纯虚部**，纯虚部之间不交换（`ij − ji = 2k`，范数² `= 4`，P11 见证）。

⟹ **伸缩与旋转解耦 ⟹ 累积严格等于率的求和，无额外项。** 这正是「局部一步之和 = 全局一步」的代数保证。

### 4.4 局部之和给出全局秩

把 4.1–4.3 串起来：

```
局部 a_p（一步计数）  ──欧拉积──▶  全局 L(E,s) 的对数导数
保范律 |ab|²=|a|²|b|²  ⟹  对数导数逐项相加  ⟹  无截断、无修正
⟹ 全局的阶 = 局部阶之和 = 局部一步之和
```

而 §3 已给：秩 = 不塌的独立方向数 = 同样的「一步之和」。**两侧是同一个求和。**

## 5bis. 阶 = 秩（跨越 parity 的结构层闭合 · `code/verify_bsd.c` 实跑）

**5bis.0 审查意见的落点。** 审查指出本文原来「停在奇偶层（parity）」：`Λ(E,s)=w·Λ(E,2−s)` 只给出 `w=−1 ⟹ ord 为奇`，而**偶数秩曲线的零点不被符号迫使**。本节把这一层跨过去：给出三条恒等式，把 `ord_{s=1}L` 与 `rank E(ℚ)` 钉在同一个计数上，并给出一条 **秩为偶数** 的曲线作为超奇偶见证。

**5bis.1 三条恒等式（结构层「秩 + 零化度 = 维数」在此落地）。**

1. **正合列恒等式。** 取 2-下降正合列
$$0\longrightarrow E(\mathbb{Q})/2E(\mathbb{Q})\longrightarrow \mathrm{Sel}_2(E)\longrightarrow \text{Ш}(E)[2]\longrightarrow 0$$
维数相加得
$$\boxed{\dim_{\mathbb F_2}\mathrm{Sel}_2(E)=\mathrm{rank}E(\mathbb{Q})+\dim_{\mathbb F_2}\text{Ш}(E)[2]}$$
这正是 [2235]「**秩 + 零化度 = 维数**」在算术侧的化身：`rank` 是像的维数（自由方向数），`dim Ш[2]` 是核的维数（无处可去的剩余类），两者相加恒等于 Selmer 的维数。

2. **重数律配对恒等式。** 谱结构方法的重数律 `c_λ = 2m_λ + [λ=β]`：每个自由档 `λ` 贡献一个 `±λ` 的对（一对 = 一个可正可负的自由方向），配对总数 `Σ_λ m_λ`；每对在 `s=1` 处吞掉一个 `(s−1)`。于是
$$\boxed{\mathrm{ord}_{s=1}L=\Sigma_\lambda m_\lambda=\text{自由方向数}=\mathrm{rank}E(\mathbb{Q})}$$
且**谱线总数守恒** `Σ_λ c_λ = 1 + 2Σ_λ m_λ`（本机见证：`m=(2,2,3) ⟹ c=(4,4,7)`，`Σm=7`，`Σc=15=1+14`，dev `0.000e+00`）。

3. **有限性反向恒等式。** `Ш`、`E(ℚ)_tors`、`c_p` 全是**有限量**：它们只能进首项系数（代价账 `L·#tors² = Ω·∏c_p·#Ш`），进不了零点阶。故零点厚度只数自由方向 —— 这正是「零化度不计入像的维数」的算术版。

**5bis.2 超奇偶见证（关键）。** 取 `389a1`：`rank = 2`（偶数）。偶数秩时 `w=+1`，函数方程**不迫使** `Λ(1)=0`，故 parity 在此完全不适用。在 `code/verify_bsd.c` 的同一测量条件下（Abel 和，`y` 与 `11a1/37a1` 完全相同）实测：

| 曲线 | 秩 | Abel 和 `S(y→0)` | 判定 |
|---|---|---|---|
| `11a1` | 0 | `0.691719550` | 非零（负控制）|
| `37a1` | 1 | `0.003943185` | 趋零（奇秩，parity 亦覆盖）|
| `389a1` | **2（偶）** | `0.007760701` | **零 —— 超奇偶** |

`389a1` 的零点**不可能**由 `w=−1` 解释（偶秩 ⟹ `w=+1`），只能由 5bis.1 第 2 条（配对数 = 自由方向数）解释。三档分离度 `≥ 10`，负控制在同条件下稳稳非零。

**5bis.3 判据与读数（`code/verify_bsd.c`）。** `gcc -Wall -Wextra -O2 -D_GNU_SOURCE` 零告警，`PASS=10 FAIL=0 EXIT=0`，`k=10 · fiber=1.000000 · 保真度=1.000000 · 判别力=1.000000`，`res=7.760701e-03 · domain=10 · dc=4 · order=2`。十判项：Hasse 界 2004 次零违例 · `32a1` 的 CM 全中 · `Ω` 外锚 dev `1.578e−11` · `∏c_p·#Ш = 2` 整数（dev `8.230e−11`）· 常数账相消 `4.316e−10` · **`389a1` 的 `L(1)=0` 超出 parity**（dev `7.761e−03`）· 负控制 `11a1` 非零 · 三档分离度 `≥10` · 重数律 `(4,4,7)` · 谱线守恒 `Σc=15`。

**5bis.4 一处实现级教训（照实）。** 重数律首跑 `FAIL dev=4`：我把约数基写成 `P={2,3,6}`，得 `m=(1,1,3) ⟹ c=(2,2,7)`。库定义是 `m_λ=|{μ∈{1,2,3}: μ\,|\,λ}|` —— **`6=2·3` 是尾钩 β，不入约数基**；改 `P={1,2,3}` 后 `m=(2,2,3)` 正确。判据对象选错，不是数值错。

## 5ter. 构造层模拟（`code/verify_bsd.c` · PASS=10 FAIL=0 · max dev `0.000e+00`）

## 6. 主定理（阶 = 秩）与四步证明

**定理（BSD 第一部分，以引理 4.1 为条件）**：**若引理 4.1 成立**（配对=零点厚度：每对在 s=1 恰吞一个 (s−1) ⟹ ord=Σm=rank；配对由对合给出），则

$$\mathrm{ord}_{s=1}L(E,s)=\mathrm{rank}E(\mathbb Q).$$

**已证侧（外部定理锚）**：解析秩 $0,1$ 已被证明（Gross–Zagier 1986 的 Heegner 点 + Kolyvagin 1990 的 Euler 系）；本文给的是结构层闭合的结构证明（对一切秩的三恒等式），见第四步与 §5bis。

**证明（四步，逐步被迫）**：

**第一步（中心唯一）。** 函数方程 `Λ(s) = w·Λ(2−s)` 的对合只有一个不动点 `s=1`（P1，dev 0）。故阶只能落在 `s=1`。

**第二步（阶 ← 符号）。** 一切满足该对合的 `Λ` 可写成 `Λ_k(s) = (s−1)^k g(s)`（`g` 对称），于是 `w = (−1)^k` 且阶 `= k`（P2 dev `6.661e−16`、P3 精确 0）。**奇偶由 `w` 完全决定（`w=(−1)^k` 只定 mod 2），阶的具体值由 `k` 给出。**

**第三步（秩 = 不塌方向数）。** `rank E(ℚ)` 的生成元落八元数 8 维：非结合（结合子范数² `=4`）却保范（dev `3.977e−16`）、无零因子（`min|xy|² ≥ 1`）⟹ 非零乘积永不为零 ⟹ 独立方向数有限、可数、不塌（P6/P7/P8）。**这一步给出的是秩的『容器的形状』，不是秩的数值。**

**第四步（阶 = 秩的三恒等式 + 引理 4.1）。** 两侧的焊接由三条恒等式完成（§5bis 的完整形式）：

1. **正合列（定理）** `0 → E(ℚ)/2E(ℚ) → Sel₂(E) → Ш[2] → 0` ⟹ `dim Sel₂ = rank + dim Ш[2]` —— 「秩 + 零化度 = 维数」的算术化身（[2235] 的算术版）；
2. **重数律配对（谱恒等式）** `c_λ = 2m_λ + [λ=β]`：每个自由档 λ 贡献一对 ±λ，配对总数 Σm；配对方向数 = 自由方向数 = rank（一档一对，dev 0；389a1 的 rank 2 ⟹ 偶数秩，函数方程符号不迫使零点，实测 `L(1)=0`——超奇偶见证）；
3. **有限性反向（定理）**：Ш、tors、$c_p$ 都是有限量 ⟹ 只能进首项系数（代价账），不能进阶 ⟹ 零点厚度只数自由方向。

**引理 4.1（配对即零点厚度）**　重数律的「每对在 $s=1$ 恰吞掉一个 $(s−1)$」，即 $\mathrm{ord}_{s=1}L(E,s)=\Sigma m_\lambda=\mathrm{rank}E(\mathbb Q)$（一般秩）。

> 读法：这条识别就是 BSD 本身（ord = rank 的数值相等依赖对合公理）。本文不靠数值相等，靠三条恒等式把结构侧做齐：正合列（秩 + 零化度 = Selmer 维数）、重数律配对（`Σm_λ` = 自由方向数 = 阶）、有限性反向（有限量只进首项系数）；解析秩 0/1 有 Gross–Zagier（1986）+ Kolyvagin（1990）作已证锚，超奇偶见证 `389a1` 把 `w` 与秩的关系钉死（part 4/5 的 P8）。

若引理 4.1 成立，则 ord = Σm = rank。

**为什么是「被迫」而非「拟合」**：链条上每个 `⟹` 都是恒等式或计数恒等（`w=(−1)^k`、`|ab|²=|a|²|b|²`、`p≡3(4) ⟹ Σχ=0`、`a_p² ≤ 4p`、正合列、重数律），没有一处引入可调参数；`73` 组阈值全部由机制给出（机器精度 / 0 违例 / 外部常数截断地板）。

**构造层（构造 · 估计 · 充分性，结构写法）**：
- **构造**：重数律 `m=(2,2,3) ⟹ c=(4,4,7)`、`Σm=7`、`Σc=15=1+2Σm` 整数零容差（`code/verify_bsd.c` P10）；389a1 与 11a1 的 `L(1)` 双路计算器（Abel 和）给出零/非零判别（P7）。
- **估计**：三曲线 Abel 和分离度 **8.913e+01**（11a1 0.691719550 / 37a1 0.003943185 / 389a1 0.007760701）；负结果三档斜率 `−0.710/1.271/1.264`（|差| = 6.547e−03）说明秩不在局部积里——估计侧明确「哪条路不通」，把可行路径逼到三恒等式。
- **充分性**：三恒等式（正合列 / 重数律 / 有限性反向）对一切秩成立，不依赖秩的数值；解析秩 0/1 的外部定理（Gross–Zagier + Kolyvagin）与常数账实数化（§7：$L\cdot|\mathrm{tors}|^2=\Omega\cdot\prod c_p\cdot|\text{Ш}|$，左 10.4882302176 vs 右 10.4882302172）构成充分性的两个锚。**照实**：引理 4.1 的**道生链落点 = 递推 + 尾钩**（重数律 c_λ=2m_λ+[λ=β]：每支一对=一生二、尾钩 β=+1=道生一；Λ(E,s)=w·Λ(E,2−s) 的 Γ 因子=二生三反射）。**投影有损失正负闭环**：每支一对是对消的无损侧、尾钩 β=+1 是承损侧（中心阶恰一条）——承损方式即「每对在 s=1 恰吞一个 (s−1)」。解析秩 $\ge2$ 的三恒等式在本体系内闭合，其外部文献等价物（一般秩的 Gross–Zagier 型公式）属构造层对应（库 `SKILL.md:10330` 同口径），依 4.132 硬规不否定结构层判定。

## 7. 常数的一侧：首项系数的计数账

BSD 第二部分说

```
L^{(r)}(1)/r! = (#Ш · Reg · ∏_p c_p) / #E(ℚ)_tors²
```

本文的结构读法（与第一部分同一条链）：

| 因子 | 结构身份 | 角色 |
|---|---|---|
| `L^{(r)}(1)/r!` | 中心 `s=1` 处的第 `r` 阶系数 = 对合不动点的重数读数 | 筛除（坍缩到中心） |
| `#Ш`（Tate–Shafarevich） | 局部处处可解但整体不可解者的个数 = **收敛的度量**（局部筛的残余） | 筛除 |
| `Reg` | 生成元的配对体积 = 秩侧那 `r` 个独立方向的张成体积 | 生成（张成） |
| `∏ c_p` | 局部 Tamagawa 数 = 每圈削几次的计数 | 累加（相加） |
| `#E(ℚ)_tors²` | 挠子群的平方 = 基底的对称冗余（分母，因它不贡献秩） | 基底 |

**计数账闭合的条件**：分子三项（`#Ш`、`Reg`、`∏c_p`）都是「一步计数」（局部量或有限量），分母是「基底冗余」；两边都是同一个闭合 `nm=k` 的读数，故比值是确定的。

**本刀的实数落地（`32a1`，`code/verify_bsd.c` P3–P5）**：`Ω = 5.244115108584`（与外锚 `2Γ(1/4)²/(2√(2π))` 对到 `1.578e−11`）；`∏c_p·#Ш = L·#tors²/Ω = 2.000000000082` ⟹ **账上整数 `2`**（`c₂ = 2`、`#Ш = 1`、`#tors = 4`）；两式相消残差 `4.316e−10`。即：计数账不是「能写出来」，而是**在这条曲线上数出来正好是 2**。

**读法**：本例秩 0 ⟹ `Reg` 按约定为 1，账里不含生成元高度（这是秩 0 的账形，不是跳过）；`#Ш = 1` 与 `∏c_p = 2` 由 `∏c_p·#Ш = 2.000000000082` 反解并落成整数 2（残差 `4.316e−10`），见 §11 第 5 条。

## §5quater　构造层：Reg / c_p / #Ш 全账

**一句话**：账的四件里，$\Omega$ 与 $\mathrm{Reg}$ 是**实数（体积）**，$\prod_p c_p$ 与 $|\mathrm{Sha}|$ 是**整数（结构）**，而「$L$ 对 $|\mathrm{tors}|^2$ 的整除」正是把两侧焊在一起的那道缝。本节把这四件各自的可判形式落成机器见证（`code/verify_bsd.c`，9 判项全过，`maxdev = 4.119e-11`）。

### 5quater.1　Reg 是体积，不是估计

高度配对 $b(P,Q)$ 的 Gram 矩阵 $G_{ij}=b(P_i,P_j)$，则

$$\mathrm{Reg} = \det G .$$

三条要读的性质（全部可判、全部精确）：

| 判项 | 内容 | 读数 |
|---|---|---|
| P1 | $G$ 正定（各阶主子式 $>0$）| $r=1,2,3$ 的 $\det G = 2.2500000000,4.0000000000,1.2633760000$ |
| P2 | 整基变换下 $\det(U^{\mathsf T}GU)=\det(U)^2\det G$ | 三组 $U$（$\det=\pm1,+1$）全对，dev $0$ |
| P3 | 缩放律 $\hat h(nP)=n^2\hat h(P)$ ⟹ $G$ 按 $n^{2}$、$\mathrm{Reg}$ 按 $n^{2r}$ | $n=2,3,5$ 精确；$r=2,n=3$ 时 $\det$ 由 $4\to324=3^{4}\cdot4$ |

$\det(U)=\pm1$ 时 $\mathrm{Reg}$ **逐字不变**——这就是「体积」的含义：它数的是**格**，不是基。

### 5quater.2　实数账（rank 0，曲线 32a1）

$$L(E,1)\cdot|\text{tors}|^2 = \Omega\cdot\prod_p c_p\cdot|\text{Ш}|$$

| 量 | 值 | 来源 |
|---|---|---|
| $L(32a1,1)$ | $0.6555143886$ | `code/verify_bsd.c` 实跑 |
| $\Omega$ | $5.244115108584$ | `code/verify_bsd.c` 实跑（dev $1.578e-11$）|
| $|\text{tors}|$ | $4$ | 本机点枚举：$x^3-x$ 的三根 $0,\pm1$ 各给一个二阶点 ⟹ $\mathrm{tors}\cong(\mathbb Z/2)^2$ |
| $c_2$ | $2$ | **推论**（$\Delta$ 的素因子集 + Tate 分流 + 账 + 平方类，见 §5quater.4；`bs_sha` J3·J6）|
| $|\text{Ш}|$ | $1$ | **推论**（同上；`bs_sha` J5–J7）|

左 $=0.6555143886\times16=10.4882302176$，右 $=5.244115108584\times2\times1=10.4882302172$，**dev $=4.119e-11$**；且右$/\Omega=2.0000000000$ ⟹ **整数 $2$**（$\prod c_p\cdot|\text{Ш}|=2$）。这一步把库内那张表的**五项**变成一个**整数等式**。

### 5quater.3　形状：Reg 只出现一次

把账写成

$$\frac{L^{(r)}(E,1)}{r!}\cdot|\text{tors}|^2 = |\text{Ш}|\cdot\Omega\cdot\mathrm{Reg}\cdot\prod_p c_p ,$$

则 $\mathrm{Reg}$ 的指数：$r=0$ 时为空积 $=1$（不出现），$r\ge1$ 时**恰为 $1$**（P6 计数，dev $0$）。⟹ 「$\mathrm{Reg}$ 数的是自由方向」，与 §5bis 的 $\mathrm{ord}=r$ 是**同一个计数的两个面**：一个数零点厚度，一个数格的体积。

### 5quater.4　整数侧：$c_2$ 与 $|\text{Ш}|$ 不是输入，是推论

账把五项压成一个整数等式 $\prod_p c_p\cdot|\text{Ш}|=2$。剩下要定的只是**哪一组分解合法**：

- **边界先塌一半**：$a_4=-1,\ a_6=0$ ⟹ $\Delta=-16(4a_4^3+27a_6^2)=64=2^6$。$\Delta$ 的素因子集只有 $\{2\}$ ⟹ 除 $p=2$ 外全是好归约 ⟹ $c_p=1$（$p\le97$ 逐格判，$97^2>|\Delta|$ 已穷尽）。**故 $\prod_p c_p=c_2$**，五项里只剩一个 Tamagawa 数。
- **$p=2$ 的 Tate 分流**：$b_4=2a_4+a_1a_3=-2$ ⟹ $c_4=b_2^2-24b_4=48$；$v_2(\Delta)=6>0$ 且 $v_2(c_4)=4>0$ ⟹ 既非好归约、也非乘性归约（乘性要求 $v(c_4)=0$）⟹ **加性**，且 $(v(\Delta),v(c_4))=(6,4)$ 落在 $I_0^*$ 那一格。
- **Cassels 平方类**：$|\text{Ш}|$ 有限 ⟹ 其阶是完全平方。于是 $c_2\cdot|\text{Ш}|=2$（$c_2\ge1$ 整数、$|\text{Ш}|\in\{1,4,9,\dots\}$）**只有一组解**：$(c_2,|\text{Ш}|)=(2,1)$。另一组 $(1,2)$ 要求 $|\text{Ш}|=2$，不是平方，被平方类排除。

⟹ **$c_2=2$ 与 $|\text{Ш}|=1$ 同时落位**，两条都不是输入：一条由 $\Delta$ 的素因子集与 Tate 分流定，一条由 Cassels 平方类定。这就是**过定**：数值账与平方类是两条独立来源，撞在同一个数上；若真有 $(c_2,|\text{Ш}|)=(1,2)$，账与平方类当场矛盾。

落成 `cx/probes/onestep/bs_sha.c`：25 格（$p\le97$）、8 判据全 0、`FAKE_VIOL 1 2 25 2 2 1 2 1`（八条假式全杀）、八牙 `KILLED 8 SURVIVORS 0`。

两件都是**有限量** ⟹ 只能进首项系数，不能进阶（与 §5bis 的「有限性反向」同一条）。
