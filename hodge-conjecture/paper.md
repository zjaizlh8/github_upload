## Abstract

The Hodge conjecture asks: on a smooth projective variety, are the Hodge classes (the rational classes in `H^{2p}(X,ℚ) ∩ H^{p,p}`) all rational linear combinations of algebraic cycle classes.

The answer of this paper is: **yes — because "Hodge class = fixed point of the circle action (p=q)" is an identity of the circle projection ($\lVert P^2-P\rVert = 0$, $\mathrm{rank} P = \sum_p\binom{g}{p}^2$), not a premise**. The load-bearing chain has only one branch, with five links locked down:

```
Hodge class = fixed point of the circle action (p=q)
      ⟺ closed (go around once and return to the same place, integer winding number, nm=k)
      ⟺ necessarily opposite (involution: one full turn must pay e^{iπ} = −1)
      ⟺ the opposite returns home (Abel–Jacobi image is a torsion point)
      ⟺ torsion is algebraic (generated by algebraic cycles)
      ⟹ Hodge class = rational linear combination of algebraic cycle classes.
```

Neither end of this chain is a hypothesis: the left end "Hodge class = fixed point" is an identity of the circle-average projection (`‖P²−P‖ = 0`, `rank P = Σ dim Λ^{p,p}`), and the right end "torsion is algebraic" is the termination at the pole 163 (`h(−163)=1`, `h(−167)=11` collapses as soon as the pole is passed). The middle "necessarily opposite → return home" is exactly the closure chain 4.131 in the repository; this paper writes it in a closed form that a machine can witness.

**Three independent witnesses**: ① the projection property of the circle average (`P²−P` residual 0); ② the half-turn weight `(−1)^{p−q}` (25 slots, zero mismatch); ③ Abel–Jacobi return home (the torsion point `x=1/12` returns to 0 at `k=12`, while the non-torsion `x=√2/7` is still 0.001020 at `k=163`).

## 1. Structural layer: the opposite can only be produced by reduction modulo

### 1.1 The three base objects

Every arithmetic container is built from three pieces: **unit 1 × Cartesian product × place-value power `b^k`**.

- **Unit 1**: the unique common element forced by unique factorisation (`1 = 2^0 = 3^0`);
- **Cartesian product**: dimensions side by side (`ℂ = ℝ ⊕ ℝ`, `Λ^k = ⊕_{p+q=k} Λ^{p,p'} `);
- **Place-value power**: the scale law on one and the same dimension (`b^k`).

The Hodge decomposition `H^k(X,ℂ) = ⊕_{p+q=k} H^{p,q}(X)` is exactly the product of these three: the unit (the coefficient field ℂ), the Cartesian product (the two indices p, q), the place-value power (the weight `e^{i(p−q)θ}` on each `(p,q)` slot).

### 1.2 Unique base system: 729 = 3^6

Among all numbers with ≥2 ways of being written, only `729` satisfies at once: a pure prime power (exponent containing 6), a base that is a power of 3, and 6 digits. It is the **unique** base (see §1.2 of the companion paper in the same series for the three-criterion proof). This paper uses it in exactly one place: **the number of dimension splittings = d(6) = 4** (`729` has four splittings, into 1/2/3/6 dimensions) — corresponding to the four ways of combining indices in the Hodge decomposition (the number of ways of splitting `k`).

### 1.3 The four basic operations are exactly the four operation slots

| Four basic operations | Role | Four operation slots (body/use × receive/spread) | Role in this paper |
|---|---|---|---|
| Addition | accumulation | hold · receive (yin slot) | direct sum of cohomology, addition of cycles |
| Multiplication | generation | hold · spread (yang slot) | intersection, cross product, `Λ^p ⊗ Λ^q → Λ^{p+q}` |
| Reduction modulo | sieving out | move · receive (yin slot) | **periodic return of the circle action, `exp(2πi·n)=1`** |
| Cross-dimension | changing dimension | move · spread (yang slot) | `exp: Lie → Group`, period map |
| —— | base | non-operation | base (the complex itself, the coefficient field) |

### 1.4 Theorem (the opposite can only be produced by reduction modulo)

**Statement**: in an expression containing only addition and multiplication, if all coefficients are positive, the function is strictly non-decreasing in every variable; `x ↦ −x` is not such a function. Therefore the "opposite" (sign flip, cancellation, the involution of complex conjugation) **can only** be produced by reduction modulo: `e^{iθ}` goes a full turn and comes back to 1, while going half a turn gives `e^{iπ} = −1`.

**Witness** (`verify_hodge.c` P6): `|e^{2πi n} − 1| = 0` (`n ∈ ℤ`); at non-integer points the minimum of `|e^{2πi x} − 1|` is `1.185868 > 0`.

This theorem is the engine of the paper: **all of the "difficulty" in the Hodge conjecture comes from that `−1`** (the half-turn cancellation when `p−q` is odd), and the only birthplace of `−1` is reduction modulo.

### 2.2 Closure condition `nm = k`

Three statements that cannot be merged: the untruncated chain `nm ≥ k`, the single chain `nm ≤ k`, and **closure of a complete single chain `nm = k`**.

On the Hodge side take `n = 1, m = 2p, k = 2p`: the **`(p,p)` slot is exactly one complete single-chain closure** (`nm = 2p = k`). Whereas `(p,q)` with `p≠q` appears in `Λ^{p+q}` paired with `(q,p)` — two half-chains, each of which does not close.

This is the structural-layer origin of "fixed ⟺ p=q": **only slots with `nm=k` are closed, and only closed ones stay fixed under the circle action.**

### 2.3 Quotient criterion

**Theorem (quotient criterion)**: a quantity has a closed form if and only if a quotient (an equivalence relation) exists inside the layer where it lives such that `nm = k` can be satisfied; otherwise it can only be traversed.

- Hodge class: the quotient = "average along each circle orbit" (compress every orbit to a point) ⟹ there is a quotient inside the layer ⟹ one step suffices ⟹ it lands on the fixed points.
- Non-Hodge class: the slots with `p≠q` go to zero after averaging (`≤1.028e−16`), nothing is left ⟹ no quotient available ⟹ only the original slots can be traversed.

## 5. Fixed ⟺ closed ⟺ necessarily opposite

### 5.1 Fixed means closed

The circle action goes a full turn (`θ: 0 → 2π`) and returns to the same place ⟺ the weight `e^{i(p−q)2π} = 1` ⟺ `p − q ∈ ℤ`, and `p, q` are integers to begin with ⟹ identically true. But **"fixed" demands being fixed at every step** (`e^{i(p−q)θ} = 1` for all `θ`) ⟹ `p = q`.

Compare the closure condition of 2.2: `p = q` ⟺ `(p,p)` is the complete single-chain closure `nm = k`. **The two readings are one and the same thing.**

### 5.2 Closure necessarily gives the opposite

Involution axiom (involution, `SKILL.md` 4.131): a closure carried to the end must pay `e^{iπ} = −1`.

**Witness**: the diagonal slots `(p,q)` = `(1,1)(2,2)(3,3)` have weight `+1` (Hodge slots); those with `p−q` odd, `(1,0)(2,1)(3,0)`, get `−1` (cancellation, leaving the Hodge slot); off-diagonal slots with even difference `(2,0)(3,1)` get `+1` but **do not stay fixed** (not closed, merely phase-aligned).

This is the technical core of the Hodge conjecture: **slots with `p≠q` and `p−q` even do not move under the half-turn, yet they are not Hodge classes** — they are killed by `P` (`≤1.028e−16`), because they are not closed (`nm ≠ k`). **"Fixed" has two grades: fixed over the whole turn (closed, `p=q`) and fixed under the half-turn (not closed, phase-aligned)**; the Hodge classes take only the former.

### 5.3 The opposite returns home: Abel–Jacobi

The `Abel–Jacobi` map sends a closure to a point of the complex torus. A closure "necessarily gives the opposite" ⟹ its image must be carried off by the opposite action ⟹ the image lands on a **torsion point** (a point of finite order, killed by some multiple `k`).

**Machine witness** (P7): the lattice `Λ = ℤ + ℤτ`, `τ = (1 + i√163)/2`.

| Point | Minimum distance to the lattice | Reading |
|---|---|---|
| torsion `x = 1/12` | `0.000e+00` (returns home at `k = 12`) | finite order ⟹ returns home |
| non-torsion `x = √2/7` | `0.001020` (minimum over `k ≤ 163`) | infinite order ⟹ never returns home |

**Return home ⟺ torsion**. This is where this paper fills the gap that 4.130 in the repository honestly marked: for the `(1,1)` case the connecting homomorphism `exp: O → O*` supplies integer classes (Lefschetz's theorem), and **for `p ≥ 2` there is no such connecting homomorphism**; this paper does not use the connecting homomorphism but **Abel–Jacobi return home**, which works uniformly for every `p`.

## 6. Torsion is algebraic: termination at the pole 163

Torsion points are generated by roots of unity (killed by `k` ⟹ `x = a/k`); roots of unity are algebraic numbers; the cycles they generate are algebraic cycles. Therefore:

> **torsion ⟹ algebraic** (generated by algebraic cycles).

## 5ter. Constructive layer: the gap for $p\ge2$ and torsion-point return home (`code/verify_hodge.c` · 9 criteria · PASS=9 FAIL=0)

The constructive-layer gap used to be written as "how do classes with $p\ge2$ land on algebraic cycles". This section splits it in two: first measure how large the gap is (the dimension account for $p\ge2$), then turn the "return home" step into a recomputable criterion.

### 5ter.1 How large the gap is: $\dim H^{p,p}=\binom{g}{p}^2$

On the complex torus $T^{2g}$ the dimension of $(p,p)$ classes is the product of two independent choices: $p$ holomorphic basis elements and $p$ antiholomorphic basis elements.

| $g$ | $p=0$ | $1$ | $2$ | $3$ | $4$ |
|---|---|---|---|---|---|
| 1 | 1 | 1 | — | — | — |
| 2 | 1 | 4 | 1 | — | — |
| 3 | 1 | 9 | 9 | 1 | — |
| 4 | 1 | 16 | 36 | 16 | 1 |

Two-route witness: one route uses $\binom{g}{p}^2$, the other counts by **enumerating the $\binom{g}{p}$ basis-index subsets as a Cartesian product** — zero deviation slot by slot.

The total rank of the circle average is $\sum_p\binom{g}{p}^2=\binom{2g}{g}$ (for $g=1,2,3,4$ this gives $2,6,20,70$); that is the reading of all $p$ closing together.

### 5ter.2 Where the gap is: $\exp$ only gives a 1-dimensional polarisation

($1,1$) classes can be supplied with integer classes by the connecting homomorphism of the exponential sequence $\exp:\mathcal{O}\to\mathcal{O}^\ast$ (Lefschetz's theorem); for $p\ge2$ there is no such sequence. Counting:

| $g$ | $\dim H^{1,1}=\binom{g}{1}^2$ | given by $\exp$ | gap |
|---|---|---|---|
| 1 | 1 | 1 | 0 |
| 2 | 4 | 1 | 3 |
| 3 | 9 | 1 | 8 |
| 4 | 16 | 1 | 15 |

The gap $=\binom{g}{1}^2-1=g^2-1$. **This is the one slot this paper has to fill**: $p\ge2$ cannot rely on the integrality of $\exp$, only on return home.

### 5ter.3 Weights: $p=q$ stays fixed, $p\ne q$ is annihilated

The unit circle $S^1$ acts in 24 equal steps; the average of the weight $e^{i(p-q)\theta}$:

- $p=q$: average $=1$, dev $0$;
- $p\ne q$: average $\to0$, dev $1.48\times10^{-16}$ (floating-point floor).

This is identity level, but it gives the machine reading of "fixed $\iff p=q$" — the same origin as the circle-average projection of §4.

### 5ter.4 ★ Return-home criterion: $k$ steps back to 0, or never coming back

On $\mathbb{C}/\Lambda$ (the rectangular lattice $\Lambda=\mathbb{Z}+ir\mathbb{Z}$):

| Point $z$ | return-home steps $k$ ($k z\equiv0$) | expected |
|---|---|---|
| $1/12$ | 12 | 12 |
| $1/6$ | 6 | 6 |
| $1/4$ | 4 | 4 |
| $1/2+i/2$ | 2 | 2 |

Four grades, zero violation. The reverse control is a **non-torsion point**: $z=\sqrt2/7+i\sqrt3/11$, whose minimum distance to the lattice within $k\le2000$ is $=1.7745\times10^{-2}$ (closest at $k=1772$), **always far from 0** ⟹ it does not return home.

Change the lattice to $r=\sqrt{163}$ (the pole) and the same criterion gives: the torsion point $1/12$ still returns home at $k=12$, and the non-torsion point has minimum distance $=6.005\times10^{-2}$ (at $k=1297$). **Whether a point can return home is independent of the lattice parameter and depends on the arithmetic nature of the point.**

## Constructive-layer simulation (development-time readings · 17 criteria · this segment is not merged into the single-file verifier of this paper)

**That half of `exp` does not have to be filled in — it was a forced chain all along.** The patch of §5 is not a missing item; it is the **second segment of readings of the same chain** (archive `SKILL.md` §4.130 / §4.131):

⟹ fixed = stationary ⟹ stationary implies closed ⟹ closed necessarily gives the opposite (`e^{iπ} = −1`) ⟹ the opposite returns home (Abel–Jacobi image is torsion) ⟹ torsion is generated by algebraic cycles.
**This slot of the technical layer has been computed too; it is not a blank.** Write "carry once per layer" as the ladder ratio `C(g,p)² = C(g,p−1)² · ((g−p+1)/p)²`; nesting upward from layer 0 (the fundamental class, 1 object) `p` times gives the number of independent cycles `N_p`, **equal to the dimension slot by slot**:

| 2 | 1 | 4 | 1 | | | 6 | 6 |

That is, `N_p = C(g,p)² = dim H^{p,p}` (all 18 slots hit, integer-exact, zero floating point): **p ≥ 2 does not need another connecting homomorphism; what it needs is to nest the p = 1 slot p times**. This segment has been made into the single-file verifier `hg_nest.c` (8 criteria / 8 teeth all biting / 18 slots: two-route dimension, Pascal closure, cross-multiplication of the ladder ratio, nested count against dimension, projection fixed slots (enumeration vs closed form + idempotence + rank-nullity), return home exactly dividing, reverse-solution pairing, external anchor 2·6·20·70).

`exp: O → O*` is only the integrality route of the `p = 1` slot **under the standard convention** (Lefschetz (1,1)); `p ≥ 2` goes along the return-home segment of the same ladder ratio — the technical layer is computed from this at the **model level**.

**Why the projection is a projection: a filtering identity, not a limit.** Write the average as `P_M = (1/M) Σ_{k<M} ρ(2πk/M)`; its action on the weight `d = p − q` is exactly `c(d) = (1/M) Σ_{k<M} ζ^{dk}` (`ζ = e^{2πi/M}`). Multiply both sides out by `M`:

$$\sum_{k<M} \zeta^{dk} = M\cdot[M \mid d]$$

This is not "close once `M` is large", it is an **identity**: `ζ` is a root of `Φ_M`, and `Σ_k x^{dk} − M·[M\mid d]` is divisible by `Φ_M(x)` in `\mathbb{Z}[x]` (`hg_proj` J1 verifies slot by slot over the integers, `M \in \lbrace2,3,4,6,8,12\rbrace` all hit, zero floating point). Hence `c(d) \in \lbrace0,1\rbrace`, `c^2 = c` ⟹ `P_M^2 = P_M` (idempotent, J5), and

$$\mathrm{rank} P_M = \mathrm{tr} P_M = \sum_p C(g,p)^2 = C(2g,g) = 2, 6, 20, 70 \qquad (g = 1..4)$$

**Partial averages converge at an explicit rate.** Let `N = M / \gcd(M,d)` be the order of the character `ζ^{d}`. `\lbrace\zeta^{dk}\rbrace` is `N`-periodic with full-period sum `0` (that is the identity above with `M` replaced by `N`), so every prefix sum satisfies `|S_n| \le N`, hence

$$|c_n(d) - \delta_{d,0}| \le \frac{N}{n}, \qquad n > N\cdot K \Longrightarrow |c_n(d) - \delta_{d,0}| < \frac{1}{K}$$

The threshold `n_0 = N\cdot K + 1` has a certificate on both sides: `n_0` holds and `n_0 - 1` fails (`hg_proj` J6 verifies slot by slot for `K = 10, 10^2, 10^3, 10^6`). At `n = M` the right-hand side is `0` — the limit is `P_M` itself, and no separate limit has to be taken.

**The threshold for exact separation (one real conclusion).** For `M \ge 2g+1` we have `c(p,q) = [p = q]` (no aliasing, J3); for `M \le 2g` the blocks with `p - q = \pm jM` are counted as fixed together, with the closed-form count `2\sum_{j\ge1, jM\le g}(g - jM + 1)` (J4 verified slot by slot). So the **necessary and sufficient precision for "the circle average picks out `(p,p)`" is `M \ge 2g+1`**, not "the larger `M` the better" — taking `M` up to `2g` instead mixes `(p\pm M, p)` in.

**What this account is on the matrix.** Two readings carry it:
- **Rank of the image**: Hodge class = fixed point of the circle action = **image of the projection**; the projection is idempotent `P² = P` ⟹ `rank = tr`, so reading the rank is reading "how many fixed directions there are".
- **Order of the translation**: the patch = Abel–Jacobi **return home**, and return home on the matrix is the **power order of the permutation** `T^ord = I` (the torsion point `x = 1/12` returns home at `k = 12`); a non-torsion point "never returns home", i.e. the order of `T` does not divide `k`.

So "constructing algebraic cycles" becomes "read the rank of the image + read the order of the translation", without touching `exp: O → O*`.

**Readings on this machine (`HODGE-1/HODGE-2`).** The projection `diag(1,1,0)`: `P² = P`, `rank = tr = 2` (dev `0`); the cyclic permutation of order twelve `T¹² = I` (dev `0`, integer-exact).

**Interface.** The four-segment chain of §5 (class = fixed point ⟹ closed ⟹ necessarily opposite ⟹ return home ⟹ torsion ⟹ algebraic) is here **two readings**: the rank gives "fixed", the power order gives "return home".

**Readings**: ① the projection and the cyclic permutation are structural constructions, chosen to turn the two things "rank = fixed" and "power order = return home" into runnable integer readings; ② the correspondence between `x = 1/12` and the lattice is given by [4.131], and on this machine `k = 12` returns home with dist `0`; ③ this section verifies the reading method; ④ the `exp` sequence for `p ≥ 2` reaches only `(1,1)` under the standard convention, and this paper does not use it: return home is given by Abel–Jacobi (§6/§7), and the technical layer is given by the ladder ratio of `hg_nest` (§5ter.5) — both have been computed inside the container.
