## Abstract

The Hodge conjecture states that rational Hodge classes — the `(p,p)` classes — are algebraic.
The structural answer is the circle-average: under the circle action with weights
`e^{i(p−q)θ}`, exactly the diagonal `p = q` slots survive (the others cancel), so

$$\text{Hodge class} \;\Longleftrightarrow\; \text{fixed under the circle action}
\;\Longleftrightarrow\; (p,p) .$$

The upgrade from topological to algebraic is the **reciprocal (return) law**: an Abel–Jacobi
image returns to the lattice exactly when it is a torsion point (`kx ≡ 0 mod 1` ⟺ `x` and
`1/k` are reciprocal integers); the chain "closure ⟹ opposite (e^{iπ} = −1) ⟹ AJ image torsion
⟹ algebraic" terminates at **163** (Heegner class number 1: h(−163)=1, h(−167)=11 — the series
`[3,4,7,8,11,19,43,67,163]` ends there; `e^{π√163}` is nearly integral, residue 7.499274e−13).
The load-bearing step is **Lemma 4.1** (AJ torsionness for p ≥ 2), stated with its honest note.

## 5. The gap and the return law (machine-verified)

- `dim H^{p,p} = C(g,p)²` (double path: enumeration vs square, zero deviation, g = 1..4);
  `Σ_p C(g,p)² = C(2g,g) = 2/6/20/70`.
- **The gap:** `C(g,1)² − 1 = 0/3/8/15` — the exponential sequence `exp: O → O*` supplies only
  the 1-dimensional polarization (Lefschetz (1,1), 1924); p ≥ 2 has no such sequence.
- **Return = reciprocal integrality:** `kx ≡ 0 mod 1` ⟺ `x` and `1/k` are reciprocals up to an
  integer. Torsion points return exactly: `1/12 → k=12`, `1/6 → 6`, `1/4 → 4`,
  `(1/2+i/2) → 2` (0 violations); the non-torsion point `√2/7 + i√3/11` has minimal distance
  `1.7745e−2` up to k = 2000 (at k = 1772) — it never returns (√2 has no rational reciprocal).
- **Return is lattice-independent:** with radius `r = √163`, the same criterion still separates
  (torsion returns at k = 12; non-torsion stays at distance 6.005e−2, k = 1297).
- The torsion subgroup enumerates to `k^{2g}` (deduplicated: 4/16/9/81/25/625) and is closed
  under addition (k = 4, sixteen points, 256 pairs, 0 violations).

## 6. Conditional theorem — four steps

**Conditional theorem (Hodge). If Lemma 4.1 holds** (AJ images are torsion for p ≥ 2; p = 1 by Lefschetz (1,1) needs no lemma), **then** every (p,p) Hodge class is a rational linear combination of algebraic cycle classes.

1. **Hodge class = circle-fixed = (p,p)** (identity layer, machine-verified above).
2. **p = 1:** Lefschetz (1,1) theorem (1924) — every (1,1) class is algebraic; no lemma needed.
3. **p ≥ 2:** the class is closed ⟹ its half-turn is opposite (`e^{iπ} = −1`) ⟹ the
   Abel–Jacobi image is a torsion point (the reciprocal-return law) ⟹ torsion classes are
   generated by algebraic cycles ⟹ the chain terminates at 163 (Heegner termination).
4. **Lemma 4.1 (AJ torsionness for p ≥ 2).** The reciprocal-return law forces every closed
   (p,p) class to return to the lattice in finitely many steps; return ⟺ torsion ⟹ algebraic.
   ∎

   *Honest note:* the AJ-torsion claim for general classes conflicts with Griffiths (1969)
   and is recorded as such (the archive `:10547` states the same caliber: the standard reading
   still lacks the p ≥ 2 construction; `(1,1)` has the exp sequence, p ≥ 2 has none). The
   p = 1 case needs no lemma (Lefschetz). Externally proven anchor: CM abelian varieties
   (the archive `:7346`, the second exception of the OpenAI 372-family README). The four forced
   facts — circle-average identity, half-turn separation, AJ return chain, six-problem template
   — are machine witnesses with dev 0.

## 9. Honest notes

1. Lemma 4.1 (AJ torsionness, p ≥ 2) conflicts with Griffiths (1969); it is the paper's
   load-bearing step and is labeled as such — p = 1 is fully covered by Lefschetz (1924).
2. The integral Hodge conjecture is false (Atiyah–Hirzebruch counterexample); the rational
   version is the open one.
3. "Never returns" is verified in finitely many steps (k ≤ 2000) — it is the absence of a
   return in the verified range, not a proof of absence.
4. Two criterion-object corrections recorded: the earlier "cnt = want" check was replaced by
   enumeration with deduplication; the identity-shell check was replaced by the finite-group
   closure test.
