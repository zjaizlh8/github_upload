# 混沌一步到位 = 判据的判据（守门员条款 G32–G37）

> 作者口径（2026-10-27）：**混沌一步到位是判据的判据，是加速计算的；非 IO 型都是秒出结果；任何公式都可嵌套——错的对的残的伤的痛的；使用方法：在对象中加数组，可以层层嵌套。**
> 本节把它写成可机械执行的条款。

---

## G32 定位：它是「判据的判据」，不是又一条判据

**判法**：任何新判据提交时，必须回答三问，缺一问即退：

1. **容器是什么**（`S¹` 圆 / 窗口 `N` / 谱 / 环长）？
2. **空间维度是什么**（对象有几个自由参数，`dc` 是多少）？
3. **对称给什么闭式**（不变量/不动点/迹/行列式）？

三问答不出 ⟹ 说明写的是**直接循环**（迭代/扫描/线性逼近），按 G35 退。

## G33 用法：在对象里加数组，层层嵌套

**判法**：判据的数据必须来自**同一个嵌套数组**，且能指到它的层：

| 层 | 写法 | 例 |
|---|---|---|
| 层内（谱） | `A[i]`：一层里的量 | `spec[15]`、`WIN[3]` |
| 层间（嵌套） | `A[i][j]`：一层里再套一层 | `A[窗口][量]` |
| 层上（闭环） | 对整张数组施加**关系函数** `r(·)` | `r2=MAC/(N·Gs)`、`r3=MAC/N` |

**硬判**：判据从数组取数，不得读游离全局（`g_*` 只能作累加器）。数组之外的数据 ⟹ 外部数据刀，退。

## G34 认对象：换关系函数，不变量就是对象

**判法**：同一张数组至少施加 **3 个关系函数**，逐一判「换窗口是否不动」：

- **不动的那几个 = 对象身份**（本会话实测：`MAC/(N·Gs) ≡ 1`、`MAC/N ≡ Gs`、`MAC−N·Gs ≡ 0`）；
- **跟着窗口走的那个 = 窗口本身**（实测 `S_N/MAC = 1.0219 / 1.0055 / 1.0022`，按 `1/N` 收敛）。

**判据写法**：`J("对象认定：{r_a≡c_a, r_b≡c_b} 同时成立 ⟹ <一句话>", dev, tol)`。
禁止只报一个关系就下结论——**一个关系分不出「对象」和「窗口」**。

## G35 加速：非 IO 秒出，禁迭代

**判法**：单支探针 wall time **> 3 s** ⟹ 退（本会话实测：闭式 0.03 s vs 直接循环 > 280 s，差 3000×）。
机械检查：
1. `main` 直接层零 `for`/`while`（已有门禁）；
2. 判据函数内的循环上界必须是**网格规模**（`nrows/cells/N`），常量上界 ⟹ 扫描找信心，退；
3. 出现 `while (t < T)`、`dt`、`epsilon` 收敛判据 ⟹ 线性逼近，退；
4. 需要 `√N` 以内的量却扫到 `N` ⟹ 退。

## G36 任何公式都能嵌套（含错的、残的、伤的、痛的）

**判法**：容器只吃**读数**，不吃“正当性”。所以正确性不能靠“公式对不对”来判，只能靠**变异必须红**：

1. 每条判据至少配 **1 个齿**（改映射 / 偏不动点 / 漏反演 / 抬 1e-3）；
2. 齿的数量 **= 该层格数**（`D3 == D3_TOTAL`），差一格即“无齿格”，退（本会话据此补了 `verify_dual` 9 格、`verify_dual_exact` 20 格）；
3. 齿只能改**关系**，不能改**数据**（改数据等于换了对象）。

**这条正是“错公式也能嵌进来跑”的原因**：嵌进来后用齿分辨——**咬得动的是读数，咬不动的是恒真**。

## G37 判据的判据：一条判据好不好，先看它的四判据数

**判法**：每条判据必须先在头注释落四数，再谈语义：

```
res   —— 跑出来的残差（禁字面常量；无 R 测试写 NA）
domain—— 项数/格数
dc    —— **被测值的值域基数**（不是参数分段数、不是对象个数）
order —— 不变阶（对合 2 / 六阶递推 6 / …）
```

`dc` 写成 `r` 的分段数 ⟹ **全 PASS 而结论错**（本会话 [791] 型事故）。
判定顺序不可颠倒：**先落四数 → 再写 chk() → 最后谈语义**。
