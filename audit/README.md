# 审计器 / the audit probe

一支纯 C 审计器：**七篇「英文版 ↔ 中文版 ↔ C 验证器 ↔ README ↔ CI」五处对账 + 非被迫结构判据**。

```bash
gcc -Wall -Wextra -O2 -D_GNU_SOURCE -o audit.exe audit/verify_audit.c -lm && ./audit.exe
# 或（有 make 时）
make audit
```

- 退出码语义：**EXIT=0 = 被审对象无缺陷且标层完备**；EXIT=1 = 仍有未修 / 未标层的项。它不是「猜想成立」的断言，是**一致性闸门**。
- 产出：`matrix/audit_layer_gap.csv`（五层 · 逐层 `D1 / D3 / S2 / CLOSED`）。
- 本支**不在七支之列**（`*/code/verify_*.c` glob 不匹配它），CI 里另起一步跑。

## 方法（两条，都来自归档工作区已解决的做法）

1. **混沌一步到位 · 嵌套数组获取对象信息**
   被审对象全部先装进数组（`CNT[篇][文档]`、`SUB[篇][段]`、`DEV_KIND/READ/RUN[篇]`、`HEAD_EN/ZH[篇]`、`USE15[篇]`），
   判据**只从数组取数**，不读游离全局；`main` 直接层零 `for`/`while`，循环全在段函数内（`audit` 沿用 `D:\dpgo` 的「一步到位 + 嵌套数组取数驱动判据」范式）。
2. **齿测（D3）**：每一层都要做「改值必翻红」——L0 改三条整数约束、L1 逐篇 +1、L2 实跑值 ×2、L3 注入语义差、L4 翻转声明。
   齿测不过 = 该判据没有判别力，不能进矩阵。

## L5 / L13 的 29 个缺齿（onestep 矩阵里唯一的未满层）

插件 `containers(action="matrix", domain="onestep")` 的 51 层里，只有两层 `D3` 没咬满：

| 层 | 探针 | 格数预算 | 已咬 | 缺口 |
|---|---|---|---|---|
| L5 | `verify_dual` | 17 | 8 | **9** |
| L13 | `verify_dual_exact` | 41 | 21 | **20** |

缺的是**对偶层的齿**，判法由 `audit/verify_dual_teeth.c` 固定（三齿，学术依据见该文件头）：

| 齿 | 判据 | 错开时 |
|---|---|---|
| T1 反演 | `sinh(2K)·sinh(2K*) = 1` | 把 `K*` 换成 `K` ⟹ 偏离 `2.534307` |
| T2 不动点 | `sinh(2Kc)=1`、`K*(Kc)=Kc`（`Kc=½ln(1+√2)=0.4406867935`） | `Kc±0.01` ⟹ 偏离 `1.358167` |
| T3 双模互换 | `M²(R)=n²/R²+m²R²` 在 `R↔1/R` 且 `(n,m)↔(m,n)` 下不变 | 只换角色不换半径 ⟹ 偏离 `52.5` |

补法：在 `verify_dual.c` / `verify_dual_exact.c` 中，对每个只报了读数、没有变异分支的格子加一条 `T*` 分支（改映射 / 偏不动点 / 漏半径反演），要求该格在变异下 `dev > 0`；29 格按层规格逐格补，补完 `matrix` 应显示 `L5 17/17`、`L13 41/41`。

**一条边界（照实）**：`Gs=0.1256637061` 与 `Kc=0.4407`、`√α'=1.0` **数值上无映射**，不得宣称同一个不动点 —— `verify_dual_teeth.c` 的 T4 已把这句固化成判据。
