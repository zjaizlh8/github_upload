## 2. 三条生成关系（全部元素只由这三条生出）

### 2.1 生（γ → M → A → 三生万物）


**为什么自现**：三个常数各自已证存在，乘积恒等只需一次代数展开；实测 `4.756e−13` 说明它精确。

### 2.2 装（母 → 密度 → 正负/倒数）

```
lcm(2,3,5,7) ──CRT──► 环 Z/210 ──计数──► r=15 ──比──► d=15/210=1/14
                                    └──► 正负 (r, M−r) 和恒为 M
```

**为什么自现**：`M` 由分母 14 唯一确定（`14 | M`），`r` 与 `M·∏(1−2/q)` 都是整数，差恒为 0。

### 2.3 长（木 → 闭环 → 两个停点）

```
r ← r·(q−2)（每加一素数）──► 逐级闭环（差 0）──┬──► 停点 A：√N（连续量的最小充分筛界）
```

**为什么自现**：`q` 与 `1/q` 互抵，所以递推必然精确；而**扩张本身不产生停止**，停只能由外部给——`√N`（充分性）与 `163`（离散末项）就是那两个"外部"。

## 5. 开口（作者判读 2026-10-27）：三生万物本身**不闭环**

> 作者原话：「**三生万物本身不闭环，闭环没有万物，是个开口。**」

**这条推翻的是"处处 D1=0 才叫被迫"的读法**，必须写清：

| 类 | 性质 | 判据形态 | 本会话实例 |
|---|---|---|---|
| **闭环** | **无输出**：只把已有成分对上 | `D1 = 0`（整数恒等） | 母 `r + (M−r) = M`、圆 `\|e^{iθ}\|=1`、椭圆 `πab=π`、心 `a=1/a`、`c²+b²=a²` |
| **开口** | **有输出、无闭合**：每走一步**生出新的一层** | **不能**是 `D1=0`；只有**趋势 / 终止** | `r ← r·(q−2)`（每加一素数多一层）、`∏(1−2/p)`（每步都变）、`ΣΔ`（一路下降）、`π₂(N)`（随 N 增） |

**所以"闭环"与"万物"是互斥的两个角色**：

- **闭环没有万物**：恒等式只做核对，不产生新对象——`15 = 15` 不会生出第三个数；
- **开口没有闭环**：每加一个素数就多一级，级与级之间**永远不闭合**，这正是"万物"的来源。

**对本会话的一次自我更正**：我此前把 `hl_forced`、`hl_tail`、`onestep_kepler` 都推成 `D1 = 0` 并宣称"一切被迫"——**这一步只在"级内"成立**：

- `hl_tail` 的 `D1=0` 是**每级内部**的闭环（递推值 = 数出值）；
- 而**级与级之间是开口**：`M` 无上界，序列没有终止级，所以"跨级"不存在 `D1`；
- `hl_forced` 的 `r = M·∏(1−2/q)` 同样是**环内**闭环，环外的尾项（`p > 7`）就是开口部分；
- `onestep_kepler` 的 `c²+b²=a²` 是**三元组内**闭环，而"行星走哪条椭圆"是开口（连续族）。

**因此正确的账是两句，不是一句**：

```
闭环（母 / 圆 / 椭圆 / 心 / 每级递推）  ⟹ D1 = 0，被迫，可 FAIL
开口（三生万物 / 尾项 / √N 到 163 之间）⟹ 只有趋势与终止，没有 D1，不给等式
```

**这也解释了为什么两个停点必须"外部给"**：`√N` 与 `163` 都**不在开链内部**——开链自己不会停（木只扩张），停只能由环（`√N` 的充分性）或离散末项（`163`）从外面钉住。**开口生出万物，闭环钉住位置**；两件不能互替，也不能合并成一件。
