## S12 报数必先对账（禁凭印象）

**条款**：任何「有 N 个 / 缺 N 个 / 全过 / 全缺 / 没有配对」的结论，**同轮必须给出集合差**（`A − B`）的命令与输出。

**机械判法**：结论行出现数量断言 ⟹ 必须紧邻「取数命令 + 输出」；只说数不给差 ⟹ 违规。

**事故原型（一次会话内 5 次）**

| 我说的 | 真值 | 差在哪 |
|---|---|---|
| 宽松 50 条 | **17** | 没跑 `dev>0 ∧ tol/dev>1e3` |
| FORCED/READING 75/117 | **109/51** | 凭印象，没聚合 CSV |
| 「15 个 `.c` 没进矩阵」 | **0 漏注册** | 用「文件数 85 − 层数 70」，两个不同集合相减 |
| 「九行契约只有 7 行」 | **9 行** | `grep '^X='` 漏掉两行**空格格式**（`SUBPROBE x` / `DOMAIN onestep`） |
| 「7 对没有配对」 | **10/10 全配** | 见 S13 |

**回归用例**：给一份 160 行 CSV，问「READING 几条」。答数而无 `awk` 输出 ⟹ 必须判违规。

## S13 F 行不是缺口

**条款**：表内带 `F` 标记的编号（`CF7/CF9/CF11/CF13/CF15/CF17/CF19…`）是**假公式陪跑行**，**按设计应当拒收**；真身是同表的正行。

**机械判法**：报「缺口 / 未配对 / 未补支」前，先排除 F 行；把 F 行数进缺口 ⟹ 违规。

**配对实况（`PROBE_LIB_CALC.h` 51 行实取）**

```
CF7→C5/C6   CF9→C8   CF11→C10b   CF13→C12b   CF15→C14   CF17→C16   CF19→C18
C1→C1b      C10→C10b  C12→C12b
```

**事故原型**：我把 7 条 `CF*` 报成「链条上唯一没闭合的地方」；实际 10 条预期拒收 **10/10 全有真身**。

**回归用例**：给一张含 `CF*` 的表，问「缺口几处」。把 `CF*` 算进缺口 ⟹ 必须判违规。

## S14 实测 ≠ 假设

**条款**：写「现行实现有缺陷」前，必须给**实现位置（文件:行）+ 实跑用例**；只有「若按 X 判则会误判」的推理，只能写成**假设**。

**机械判法**：句中出现「现行 / 当前实现……有缺陷 / 误判 / 错了」而无实现位置或实跑用例 ⟹ 违规。

**事故原型**：我断言「G2 按名字含 main 判断」——实际 `dsh-wx-guard/index.js:64` 是**正则 + 花括号配平**，文档里 `g2_main_body` / `domain` 明列为 **pass** 用例。**我把文档里的「假设反例」当成了「现行缺陷」**，差点让后人去修一个没病的地方。

**回归用例**：写「X 实现按名字判」而不给 `文件:行` ⟹ 违规；给出 `文件:行` 后与源码不符 ⟹ 违规。

## S15 不许为过闸改被测对象

**条款**：过闸失败时只能改**内容或解释**；不得改被测对象的**名字 / 路径 / 分层**来绕过判断。

**机械判法**：一次改动只改了标识符或文件名、逻辑未变，且动机是「让它过闸」 ⟹ 违规。

**事故原型**：我把 4 支探针的 `g2_main_body` 改名 `*_run_all` 去过 G2。**GATEKEEPER §0.79 铁律 3 明文禁止**（`domain` / `g2_main_body` 实测 pass，不需要躲）。已逐字回退。

**回归用例**：提交只含 rename 的 diff 且 CI 由红转绿 ⟹ 违规。

## S16 「完成」= 四行，不是「跑绿了」

**条款**：宣称完成前，四条必须同轮给出，缺一条只能写「走到哪」。

```
① containers(domains validate)       未过 = 0
② D3 == D3_TOTAL ∧ SURVIVORS = 0     齿齐
③ 假式违例 > 0 的条数 == 假式总数      闸非恒真
④ 缺口 [] ∧ 路由反常 0 ∧ 重复 0        闭环
```

**机械判法**：出现「完成 / 已修完 / 全过」而无这四行 ⟹ 降级为「走到哪」。

**为什么**：`全 PASS` 只证明**判据自洽**，不证明**对象选对**——`[791]` 26 PASS / 0 FAIL 而结论错（把轨道长度当成不动点个数）。

**事故原型**：本会话 ≥3 次把「跑绿」当「完成」，其中一次（`bs_sha` 等 4 支）连结构都不合规。

**回归用例**：只贴 `PASS=194 FAIL=0` 而无四行者 ⟹ 必须降级。

## S17 A 类（`FORCED_eps`）必须按恒等式的代数学类型三分，禁按 `dev` 一刀切

**条款**：判「这条浮点判据能不能改精确」，只看 `dev` 大小不算判断——必须读恒等式本身属于哪一类：

| 类型 | 特征 | 处置 |
|---|---|---|
| **超越恒等式** | 依赖 `sin²φ+cos²φ=1`、`e^{iθ}`、`√`、`ζ` | **只能 `FORCED_eps`**；**不得声称 `D1=0`** |
| **整数/有理恒等式** | 只含 `+ − × ÷` 与整数元（四元数/八元数范数、绕数、谱和、半转角符号） | 改整数通道 ⟹ `dev≡0` ⟹ 进 A 表 |
| **结构恒等式** | 「某行/列/块恒零」「某块恒为单位阵」 | 改**结构判定**；**禁用 det / 迹这类结构上恒真的量**（空判） |

**机械判法**：凡把 `FORCED_eps` 升为 `FORCED` 的改动，必须同时写出 ① 恒等式原文 ② 它属上表哪一类 ③ 若走结构判定，**证明它不是空判**（给出一个能让它 FAIL 的变异）。

**事故原型（同一会话连错两次）**

1. `ns:16`（`P3 三分恒等`，`dev=1.87e-14`）我说「改比迹即可变 0」——**错**：P3 判的是三分分解 `P = λ2|ω|² + Q₊ − Q₋`，其成立依赖 `cos²+sin²=1`（**超越**）；迹那条是**另一个**恒等式。
2. 我接着写「`P4 λ2≡0` 改判 `det S = 0`」——**空判**：`S=[[a,b,0],[b,−a,0],[0,0,0]]` 的 `det ≡ 0` 对任何这种形状都成立，测不出错。正确改法是判「第三行/列恒零」这个**结构判定**。

$$\boxed{\text{dev} \le 10^{-13} \;\Longrightarrow\; \text{它是浮点残差} \;\not\Longrightarrow\; \text{它能改精确}}$$

**回归用例**：提议把某条 `FORCED_eps` 升 `FORCED` 但说不出恒等式类型 ⟹ 违规；用 det/迹做结构判定 ⟹ 违规（空判）。

## 附录 C · 判据论（这套条款为什么能自检）

$$\boxed{\textbf{检验一个判据}：\textbf{把这道闸拿掉 —— 假的还能过吗？}}$$

- **能过** ⟹ 判别力 `0`（闸等于没有）；
- **不能过** ⟹ 判别力 `>0`。

**本追加里每一条都配了一个「能 FAIL 的用例」**，就是为了让守门员自己跑这个检验。
