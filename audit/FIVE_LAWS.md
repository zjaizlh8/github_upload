# 五法（守门员可执行版 · 2026-10-27 定稿）

> 用途：**任何「一步到位」探针/判据/文档，头注必须声明五法并给对应判据**。缺任一法 ⟹ 退回。
> 头注写「四法」⟹ **直接违规**（旧版，缺第五法）。
> 每条：内容 · 判据形态 · 机械判法 · 实跑实例（**实例一律给源：探针名 + 输出档/md5**）。

---

## 0. 一句话总纲

> **升维（乘法）→ 降维（取模）→ 还回来（无损归心）→ 付残差（指数对数）→ 对消干净（加法）。**
> 五步少一步就不是一步到位；少归心就丢信息，少取模就压不回有限。

---

## 1. 加法 —— 维度内并列

| 项 | 内容 |
|---|---|
| **内容** | 同一维内加减；负正对消；奇数步归零 |
| **判据形态** | `D1 = 0`（对消干净），且必须能 FAIL |
| **机械判法** | 判据须是"和 ≡ 常数"的整数恒等；给不出整数可判量 ⟹ 退回 |
| **实跑实例** | 环断面和恒等 `r+(M−r)=M`：源 `onestep_tide`（`_矩阵输出.csv` L66 · `md5 551c6059…`），六级 `M=30…9699690` 正负差 `−24 … −8942340` 全成立 |
| **实跑实例** | 相位两步归零 `e^{iπ}+1`：源 `onestep_ellipse`（`md5 ee0bd3e4…`），`dev 2.348e−16` |
| **违规** | 把"和恒为 M"当潮汐（和永远不动）；用浮点残差冒充 `D1` |

---

## 2. 乘法 —— 维度外张成

| 项 | 内容 |
|---|---|
| **内容** | 乘一次升一维；增长基 = 收敛半径的倒数 |
| **判据形态** | 整数递推恒等 `x_{k+1} = x_k·f(q)`，逐级与数出对账 |
| **机械判法** | 必须给「递推值 vs 逐个数出」的差；差须为 0 或给机制界 |
| **实跑实例** | `r(Mq)=r(M)(q−2)`：源 `hl_tail`（`md5 83747865…`），`3 → 15 → 135 → 1485 → 22275 → 378675` 与逐个 `gcd` 数出**六级差 0** |
| **违规** | 只报结果不给递推；递推不与数出对账 |

---

## 3. 取模 —— 降维约束

| 项 | 内容 |
|---|---|
| **内容** | 乘法升维 + 取模降维 ⟹ `O(log N)`（一步到位的全部秘密） |
| **判据形态** | 周期闭式 `x(N) = c·⌊N/M⌋ + 余项`，余项 `< M` 有界 |
| **机械判法** | 必须同时给：闭式值、数出值、余项上界；缺一退回 |
| **实跑实例** | `r(N)=15⌊N/210⌋+r_partial`：源 `hl_elder`（`md5 31f164ad…`），`N=1e5/1e6/5e6/1e7` 四档闭式=数出 `7143/71427/357143/714285`，`res=0` |
| **违规** | 只取模、不说明模结构（等于截断，见第五法） |

---

## 4. 指数对数 —— 跨维度

| 项 | 内容 |
|---|---|
| **内容** | 跨维度时整数域不封闭 ⟹ **必然付残差**；残差斜率 = `π` |
| **判据形态** | 残差量（**不是** `D1`），必须给"付了多少" |
| **机械判法** | 含 `e^{…}` / `ln` / `π` 的判据必须单独打残差行；残差为 0 反而要怀疑 |
| **实跑实例** | `M(P)` 对 `e^{−γ}` 偏差 `2.186e−05`、`A(P)` 对 `C₂` 偏差 `4.474e−08`：源 `hl_euler`（`md5 365c03cb…`） |
| **实跑实例** | `e^{π√163}` 尾数 `7.499e−13`：源 `hl_163_e`（`md5 7b0081bd…`）—— **需 `dps≥100`，双精度判不了，本支只标不算** |
| **违规** | 把 `exp/log` 残差当误差抹掉；用双精度声称验证了 `1e−13` |

---

## 5. 无损归心 —— 可逆回 1（**新增，旧版缺**）

| 项 | 内容 |
|---|---|
| **内容** | 每个操作必须有**无损逆**，能回到心 `1`（`1 = 2⁰ = 3⁰` 唯一公共元素） |
| **判据形态** | `R(R(x)) = x` 精确（或 `≤ eps`）；同构（CRT：`Z/M ≅ ∏Z/q`） |
| **机械判法** | 头注须有 `无损归心=<可逆判据>`；探针内至少一处 `R(R(x)) − x` 读数 |
| **实跑实例** | `max|R(R(s))−s| = 5.551e−17`：源 `rh_chi`（`md5 954b57e9…`） |
| **实跑实例** | `e^{iπ}·e^{iπ} = 1`（Z₂ 闭环）：源 `onestep_genesis`（`md5 6a747b64…`） |
| **违规** | 只做取模不做归心（丢信息）；把 `N mod 210` 当"降维成功" |

### 3 与 5 必须配对（最重要的一条）

```
取模本身有损（N mod 210 丢掉 N）
只有模分解是同构（CRT）时，降维才无损
⟹ 取模降维，无损归心把它还回来；两者配对才叫一步到位，单用取模只是截断
```

---

## 6. 四条配套铁律

1. **凡一步到位必含取模**（否则退化为逐项扫，`O(N)`）；
2. **凡跨维度必付残差**（残差为 0 反而可疑）；
3. **凡取模必配无损归心**（否则是截断不是降维）；
4. **判据必须能拒假公式**（至少一齿，`SURVIVORS = 0`）。

## 9. 猜想（2026-10-27 · 作者提出）：四法被第五法收

> **猜想**：第五法「无损归心」不是第五个并列项，而是前四法的**共性**；四法是它在四种"中心"上的投影。

### 9.1 猜想的形式

| # | 法 | 逆运算 | 回到哪个中心 | 在整数域上无损吗 | 损失表现 |
|---|---|---|---|---|---|
| 1 | 加法 | 减法 | **0** | **是** | 无 ⟹ `D1 = 0` |
| 2 | 乘法 | 除法 `× q/(q−2)` | **1** | 有理上**是**，整数上要看整除 | `q` 与 `1/q` 互抵 ⟹ `D1 = 0` |
| 3 | 取模 | CRT 还原 | **环基 `M`** | **仅当模分解为同构** | 不同构 ⟹ 截断（丢信息） |
| 4 | 指数对数 | `ln` / `exp` | **出发点 `x`** | **否**（整数域不封闭） | 残差：`2.186e−05` / `4.474e−08` / `7.499e−13` |
| 5 | **无损归心** | —— | **1**（`1 = 2⁰ = 3⁰`） | **这是条件本身** | —— |

**一句话**：**每种运算都是"一次归心 + 一份损失"；损失的有无与大小，决定了它属于哪一法。**

### 9.2 猜想对现有数据的预测（已对上）

| 预测 | 证据 |
|---|---|
| **无损类 ⟹ `D1 = 0`** | 加法（`onestep_tide` 六级 0）、乘法（`hl_tail` 六级 0）、取模+CRT（`hl_elder` 四档 `res=0`） |
| **有损类 ⟹ 有残差** | `hl_euler` `2.186e−05`、`4.474e−08`；`hl_163_e` `7.499e−13`（需 dps≥100） |
| **有损但可控 ⟹ 可给机制界** | `onestep_kepler` 的浮点部分 `3.639e−12`（`√(N⁴−1)` 无理，只能给表示误差） |

**观察**：72 支探针里，凡 `D1=0` 的都能指出一条**精确逆**（加减、q 与 1/q、CRT 还原）；凡有残差的，都是逆**不精确**（`ln∘exp`、`√` 无理）。

### 9.3 可证伪条件（这条必须写在明处）

猜想**不是**空的——它给出三条可被推翻的预测：

1. 若找到一支探针：**有精确逆**但 `D1 ≠ 0` ⟹ 猜想被推翻（无损却对消不干净）；
2. 若找到一支探针：**无精确逆**但 `D1 = 0` ⟹ 猜想被推翻（有损却恰好闭合）；
3. 若某种运算既不属于上述四种中心、又能归心 ⟹ 出现第六法，猜想需扩写。

**目前 72 支里三条都没有出现**，所以猜想**尚未被推翻**，但**也未证明**——它现在是"与全部实跑不矛盾的结构判读"，不是定理。

### 9.4 与总纲的关系

若猜想成立，则总纲可压成一句：

$$\textbf{一步到位} \;=\; \textbf{做一次归心，并把损失记在账上}$$

- **损失 = 0** ⟹ 结构量 ⟹ `D1 = 0`（可作判据）；
- **损失 > 0** ⟹ 过程量 ⟹ 只报残差 / 趋势（不判结构，见 S1）。
