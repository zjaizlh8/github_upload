# 一步到位的计算发生与推演方法 —— 以「钟摆的来回」为例

> 写档日期：2026-10-27 · **每个实测数都在同一行注明探针与 md5**。
> **本文只讲"怎么算、怎么推"，不重复结论。**

---

## 零、一句话

$$\boxed{\text{一步到位} = \underbrace{\text{三问定容器}}_{\text{道}} + \underbrace{\text{数组一次装进}}_{\text{术}} + \underbrace{\text{一次取出读判据}}_{\text{数}} \qquad\Big|\qquad \text{推演} = \text{数} \to \text{道} \to \text{术}}$$

**它不是"算得快"，是"先决定用什么容器，再决定怎么装，最后才读数"。**

---

## 一、钟摆的来回（对象侧：这个结构长什么样）

### 1.1 载波：一根频率为 `γ₁` 的摆

$$\rho-1 \;\approx\; A(u)\cos\bigl(\gamma_1 u+\Phi(u)\bigr),\qquad u=\ln L=\ln\ln x$$

| 量 | 值 | 源 |
|---|---|---|
| `γ₁`（ζ 第一零点，**外部先验**） | `14.134725142` | 与数据无关的数学常数 |
| 载波周期（`u` 轴） | `2π/γ₁ = 0.44452` | 由 `γ₁` 算 |
| **半周期（过零间距）** | `π/γ₁ = 0.222261` | 实测两端 `0.213902` 与 `0.225896`，均值 `0.219899`，**−1.06%**（源: 探针 `hl_rho_seg` 输出行「过零次数 = 3 · L = 14.2536 17.6531 22.1272」，md5 `ca570b06…`） |

**过零是"半个来回"**：

$$\text{一圈（来回）} = 2\times\text{过零间距}$$

### 1.2 包络：不是"慢慢停下来"

对 `A(u)` 做幂律拟合（749,999 个取样点）：

$$\alpha = 25.17 \pm 31\%\quad(\text{rms}=0.312)$$

（源: 探针 `hl_lockin` 输出行 `gamma1 : n=450000  alpha=25.1695  lnA 散度 rms=0.3118`，md5 见 `run_probe` 记录）

$$\boxed{\text{包络的 } e\text{-folding 尺度} = \frac{u}{\alpha} = \frac{2.5}{25.17} = \mathbf{0.0993}}$$

### 1.3 尺度分离的判决（本轮最重要的一步）

$$\frac{\text{包络尺度}}{\text{载波周期}} = \frac{0.0993}{0.44452} = \mathbf{0.223}$$

$$\boxed{\text{包络比载波快 4.5 倍} \;\Longrightarrow\; \textbf{没有尺度分离}}$$

**三个后果全部实测**：

| 想做 | 需要 | 实测结果 |
|---|---|---|
| 提出极值（测幅度） | ≥2 个完整周期 | 极值间距是步长 0.0720 的 3–4 倍 ⟹ 锯齿（源: `hl_rho_phase` 输出「物极必反点（仅供示意·不作判据）」段） |
| 锁相解调（剥载波） | 窗口 ≫ 周期 **且** ≪ 包络尺度 | 空集：`0.4445 ≫ W ≫ … ≪ 0.0993`（源: `hl_lockin` 三种载波 `γ₁/γ₂/2γ₁` 给出**完全相同**的 `alpha=25.1695` ⟹ 解调无效） |
| 用相位漂移测阻尼 | 慢变包络 | 假设被 0.223 这个比值证伪 |

$$\boxed{\text{不是"数据不够"，是"两个尺度不可分"}}$$

### 1.4 可测 / 不可测的分界

| 量 | 可测？ | 为什么 |
|---|---|---|
| **相位**（过零位置） | ✅ | 过零只看相位，不看幅度 |
| **周期** `π/γ₁` | ✅ | 一次过零间距即给，−1.06% |
| **幅度指数 `α`** | ❌ | 极值要 ≥2 周期；锁相要尺度分离；两者都缺 |
| **阻尼比 `ζ`** | ❌（曾报 `1.8e−3`，已降级） | 依赖"慢变包络"，被 0.223 证伪 |

## 二、计算如何"发生"（一步到位侧）

### 2.1 四问：先定容器，再动手

| # | 问 | 答不出会怎样 |
|---|---|---|
| ① | **容器是什么** | 就会把"20 个窗口"当成对象 |
| ② | **空间维度是什么** | 就会把"模 2 的两个类"当成两个类 |
| ③ | **对称给出什么闭式** | 就会去写数值积分 |
| **④（本会话新增）** | **要分离的两个尺度，比值是多少** | 就会去做锁相、去筛 `1e12` |

$$\boxed{\text{第 ④ 问是第 ③ 问的兜底：对称存在但尺度不分离时，闭式仍不可用}}$$

### 2.2 数组：不是"多点取样"，是"一次装进"

**错的做法**：只取 20 个窗口 ⟹ 相位分箱每箱 ≤1 点 ⟹ 失败。

**对的做法**：**筛一趟，把每个点的 `π₂` 都装进数组**。

```
筛 3e9 一趟（31 s，375 MB 位图）
  ⟹ 每 2000 个奇数取一点 ⟹ 749,999 个点
  ⟹ 数组 A[j] = (u_j, ρ_j − 1)
```
（源: `hl_lockin` 输出行 `取样点数 = 749999 · u=ln L 范围 [2.1156, 3.0829] · 步长 0.08025`）

$$\boxed{\text{"筛一趟"不是"算一次"，是把整个对象装进数组的一次动作}}$$

### 2.3 一次取出：从数组读数，不边算边判

| 从哪个数组取 | 取什么 | 得到 |
|---|---|---|
| `A[j]` 的 `ρ−1` 极值 | 幅度 | ❌ 锯齿（尺度不分离） |
| `A[j]` 的过零 | 相位 | ✅ `π/γ₁`（−1.06%） |
| `A[j]` 乘载波再滑窗 | 包络 | ❌ 窗口无解（空集） |
| `A[j]` 直接幂律拟合 | `α` | ✅ `25.17 ± 31%` |

$$\boxed{\text{同一个数组四种取法：两种成功、两种失败——失败原因同一个（尺度）}}$$

### 2.4 反演：从数组反写公式

$$\text{数组} \to \text{周期 } \pi/\gamma_1 \to \text{载波 } \cos(\gamma_1 u) \to \text{包络 } A(u)\propto u^{-\alpha} \to \text{尺度比 } \frac{u/\alpha}{2\pi/\gamma_1}$$

**最后那个比值（0.223）才是"这个公式能不能用"的判据**——不是公式本身。

## 三、推演方法：数 → 道 → 术

### 3.1 数：校对数据线路（每条恒等式都要验）

| 线路 | 恒等式 | 实测 |
|---|---|---|
| `C₂R₀` | `= 4C₂M²` | `0.8324290657`（两式同数） |
| 乘积侧 | `P₂L² → C₂R₀` | 差 `1.84e−04` ⟹ **已到位** |
| 积分侧 | `Li₂L²/x → 1` | 差 `1.14e−01` ⟹ **远未到位** |
| 归一化 | `xP₂/(2M²) = 2C₂x/L²` | 差 `1.84e−04` |
| 比值 | `R₂/ρ = (1/2M)(Li₂L²/x)/(P₂L²/C₂R₀)` | `0.991990`，与式一致 |

（源: 上述五行由 `P₂(1e9)=0.0019387`（`hl_recip_force` 输出）、`Li₂(1e9)=2594292.858661`（级数）、`π₂(1e9)=3424506`（筛）三数实算）

$$\boxed{\text{校对发现：全部恒等式对得上，差的是\textbf{收敛速度}（620 倍），不是算错}}$$

### 3.2 道：从数据线路画结构线路

$$\text{计数} \;\to\; \begin{cases} \div Li_2 \Rightarrow \rho\ (\text{灵敏，步长 }1e−3/\text{decade}) \\ \div P_2 \Rightarrow R_2\ (\text{粗，步长 }1e−1/\text{decade}) \end{cases}$$

**结构线路只有一个汇合点：计数除以分母。**

$$\boxed{\text{同一个 } \pm10^{-3} \text{ 摆动：}R_2 \text{ 看不见，}\rho \text{ 全暴露} \;\Longrightarrow\; \rho \text{ 是灵敏仪器}}$$

### 3.3 术：结构线路决定操作

| 位置 | 用哪一法 | 为什么 |
|---|---|---|
| `x → L` | 指数对数 | 跨维度，**必付残差**（`Li₂` 的 `1+2/L`） |
| 计数 | 加法 + 取模 | 逐项加、按环取模（`r≡Ω`） |
| 分母 `P₂` | 乘法 | 逐素数乘，已到位 |
| 分母 `Li₂` | 跨维度 | 级数，未到位 |
| **汇合点（比值）** | **归心（第五法）** | 只有它能判"比值是否回到 1" |

### 3.4 反演的第一条硬约束

$$\boxed{\text{反演出的公式，先算它的\textbf{尺度比}；比值为空集 ⟹ 公式不可用，不管它多漂亮}}$$

**实例**：`A(u)\cos(\gamma_1 u+\Phi(u))` 这个式子**完全正确**，但尺度比 0.223 ⟹ 里面的 `A(u)` 取不出来。

## 五、写死的六条

$$\boxed{\text{① 容器先定：对象是"一趟筛的整张表"，不是"几个窗口"}}$$

$$\boxed{\text{② 数组一次装进，判据一次取出——不边算边判}}$$

$$\boxed{\text{③ 有闭式禁筛（S18）；有闭式但分辨率不够，也不许筛}}$$

$$\boxed{\text{④ 要分离两个尺度，先算比值；比值为空集 ⟹ 换方法，不换参数}}$$

$$\boxed{\text{⑤ 反演出的公式，先查尺度比，再查数字}}$$

$$\boxed{\text{⑥ 层不能用量量：问"这一层闭合没有"，不问"完成了几分之几"（四象不闭合是定义）}}$$

## 六、收束

$$\boxed{\text{钟摆的来回告诉我们：}\textbf{能测的是相位，不能测的是幅度；原因不是精度，是两个尺度贴在一起}}$$

**而一步到位之所以"一步"，是因为它在开算之前就回答了"这个量能不能被取出来"。本会话七次返工，每一次都是把这个问题推到了算完之后。**

# 七、公式可以错，表不会错（2026-10-27 · 本会话的核心操作律）

> 用户口径：「哪怕普通公式是错的，它都能给你答案。」

## 7.1 一句话

$$\boxed{\text{一步到位给的是\textbf{值}，不是\textbf{式}；表里的每个数是"乘出来的"，不是"套出来的"}}$$

**公式是人对结构的猜测；表是操作本身的产物。猜错公式，不污染产物。**

## 7.2 本会话三次实证（全部同一型）

| # | 被信错的公式/假设 | 靠公式得出的错结论 | 表给出的正解 |
|---|---|---|---|
| 1 | `Li₂` 用均匀 Simpson（`h≈500`） | `ρ` 的"振荡" | 级数法表：`Li₂(1e9)=2594292.858661`，Simpson 偏 `1.29e−4` |
| 2 | 「一个十倍程 = 一个相位周期」 | 「`ν=4` 破」 | 40 窗 × `j=1..5` 表：`ν=4` 判别力 `475×`，没破 |
| 3 | `C(ν)=e^{−νγ}K/[∏(1−1/p)]^ν` | 「`ν>2` 也有闭式」 | 120 档表：`ν≤2` 差 `≤1.1e−4`，`ν>2` 差 `4.7\~80×` |

$$\boxed{\text{三次都是：\textbf{表对，公式错}}}$$

**第 3 次最干净**：表不是"用来验公式"的，**表本身就是交付物**——`ν>2` 无闭式，但 `C(ν)` 有值。

## 7.3 为什么表不会跟着公式错

因为表里的数只经过**四种运算**，不经过任何"结构假设"：

$$\text{加法（累加计数）}\quad\text{乘法（逐素数累乘）}\quad\text{取模（环内折叠）}\quad\text{指数对数（跨维度，明码付残差）}$$

**公式则要额外赌一句"结构长什么样"**（`Li₂` 该用什么求积、一程算几个周期、Γ 在不在这里）——**赌错就全错，而表照旧。**

## 7.4 但表也会错，错在"层数不够"

$$\boxed{\text{单系统（一层）：NA——无比值可言} \;\Big|\; \text{层数}<\nu:\ 1.5\sim2.1\times\ (\text{破}) \;\Big|\; \text{层数}\ge\max(2,\nu):\ 243\sim1888\times\ (\text{生})}$$

**（§74 的 16 格实测）**

**所以表的前提不是"公式对"，是"层数够"。** 层数够 ⟹ 判据住在层间 ⟹ 落差就是答案。

## 7.5 操作清单（照这个顺序，不会跑偏）

| 步 | 动作 | 反面教材 |
|---|---|---|
| 1 | **答四问**：容器 / 维度 / 对称给什么闭式 / **要分离的两个尺度之比** | 有闭式还去筛 1e12（§47） |
| 2 | **一趟筛，全装进数组**（不是取几个窗口） | 20 窗相位分箱（§51） |
| 3 | **多维嵌套**：`(i,j,k)` 各施一个关系 | 只看一层就下结论（§74） |
| 4 | **一次取出，判据用落差**（最平/次平、最密/次密） | 拿绝对值阈值判（§58） |
| 5 | **三齿**：换一个量必须失配 | 阈值非机制给（§28） |
| 6 | **对外对照**：公开表 / 已知常数 / 已知阶 | 只在内部自洽（§69） |

## 7.7 一句

$$\boxed{\text{公式会骗人，表不会——只要层数够、齿够硬、对外对得上}}$$
